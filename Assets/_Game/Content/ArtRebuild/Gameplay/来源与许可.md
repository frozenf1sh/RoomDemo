## 开场修订追加

- 空白亚麻开局；任务画仍取材本项目实际场景，四个静物色层按真实模型深度生成几何分色。`静物真实几何分色.png` 是项目技术遮罩，1024×800，不是概念图裁剪或外部绘画图片。四层依次由玩家主动落笔，没有新增第三方图像。
- `AtelierMotifID.shader` 只在 Editor 生成分色；玩家材质使用 `AtelierTaskPainting.shader` 的亚麻纤维、逐条干湿笔触、有限手势预览及局部水纹。使用 Unity URP 官方库，随包保留原许可。
- 交稿便条复用现有微翘纸网格，派生无涂色旧纸材质；中文正文为本项目新写，仍用 Noto 字体。放大纸面供阅读，实体便条保留在桌上。
- 本次没有新增下载，没有将 AssetIntake 候选记为采用。手部、握笔接触 Foley 和真人鼠标拖笔复核仍有缺口。

## 实体点灯追加

- 左侧检视复用正式 [Vintage Oil Lamp](https://polyhaven.com/a/vintage_oil_lamp)，Poly Haven CC0。沿用原扫描灯身、陶瓷与玻璃材质；仅在玩法副本把玻璃灯罩预先放在桌上，露出灯芯。原始模型、共享材质、美术基线未改。
- 火柴纸套、抽屉、六支木杆和药头、砂纸压痕、棉灯芯、三维火苗均为项目原创 Editor API 网格；纸盒采用真实厚度和空腔。没有新增下载、外部图像或待验收素材。
- `AtelierHandledPaper.shader` 通过对象空间纤维、墨色磨损与污痕表现旧纸盒；`AtelierWickFlame.shader` 在连续三维曲面上锚定火苗根部，程序化热流只扰动上端。两者使用 Unity URP 官方库，沿用随包原文许可。
- 画中灯亮色仍使用项目现场重绘及原创短笔触 Shader，局部暖色釉层与灯芯响应由运行时数据驱动，不使用概念图取样。
- 火柴操作已具有限时燃烧与灯芯接触判定；目前没有手部模型、握持遮挡、划燃及灯芯接触 Foley。这些仍是演出缺口，不能称为完整手部动画。
