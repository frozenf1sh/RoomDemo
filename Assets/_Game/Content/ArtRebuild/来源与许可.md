## 项目原创与既有程序化表现

- 新画室墙体、倒角木作、画架结构及紧固件、厚屋顶、曲面帘／布／纸、车制陶杯／铜灯、书本、小屋的窗洞／瓦片／基础／烟囱、坡地、分叉枝叶及远山：本项目 Editor API 生成的可编辑网格。首版自制小屋与树木已停用，现改用下表的完整授权旧屋和扫描植被。
- `Textures/未完成的山谷油彩习作.png`、`山谷铅笔构图.png`：`AtelierFinishing.cs` 的数学构图与干笔算法生成；不读取 AI 概念图，不包含星空贴图。
- `Textures/数学生成_屋顶干刷残留.png`：`AtelierPresentation.cs` 生成的灰泥残留颜色／透明度遮罩；仅用于屋顶边缘，不作为天空。
- 星空：复用既有 `LivingSky` Prefab、`LivingSkyController`、`GpuPigment` 与 `ApprovedSkyPaint.hlsl`。新增场景专用 `AtelierLivingSky.shader` 使用保持局部形状的方向投影，复用原金色星点、蓝紫涡旋与实时颜料场；首版的方向哈希细星已经撤下。`_Pigment` 是运行时 RenderTexture；没有外部星图。
- 没有采用五张 AI 概念图的整图、裁片或改色图；没有采用 `NarrativeNightSky.png` 或 `QuietStarrySky` 路线。
