## 操作与交付

运行 `Builds/StandaloneOSX/RoomDemo.app`。正常画面没有常驻标题、日序、重开或大笔记按钮；N 打开笔记，Esc 打开暂停菜单。首次教学、悬停与新发现只短暂出现，小型未读提醒在打开笔记后消失。

[第三方资产清单与许可](../../Assets/ThirdParty/LICENSES.md) 包含新增家具、自然模型、表面纹理、实际大小与来源。试玩包旁的字体和模型许可证需要一起分发。

复录三个片段：

```sh
Builds/StandaloneOSX/RoomDemo.app/Contents/MacOS/RoomDemo \
  -roomDemoVisualCapture /tmp/roomdemo-visual-final \
  -screen-width 1600 -screen-height 900 -screen-fullscreen 0 \
  -logFile /tmp/roomdemo-visual-final.log
```

默认启动不会运行录制入口。主场景用增量美术安装器维护，禁止灰盒生成器覆盖人工场景。

本轮统一流水线通过：编辑模式 53/53、运行模式 29/29、场景校验与 macOS 构建。最后的织毯／木纹与特写构图调整另经编译、运行画面和构建检查，没有重复执行全套测试。构建保留 Unity 工具包未配置运行连接的提示；正式程序不会启用开发连接。
