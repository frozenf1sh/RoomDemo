# 悬停金光实验

日期：2026-10-14。当前阶段仅做 TA 与美术可行性验证，未接入 `AtelierPlayable` 或 `AtelierNight`。

## 美术目标与方案评估

最新参考使用内置生图工具重新生成，文件为 `Logs/HoverGold/Reference/疏松断续金色游丝参考.png`，原始提示词在同目录的 `疏松游丝生成说明.md`。先前密集、闭合的编织参考已弃用；这些图都只作美术方向参考，不导入运行时或 Git。

当前效果是在物品外侧浮现三缕松散的局部游丝。三段金丝本身沿每缕曲线顺时针绕行，中心、头尾和空段位置一起前进，默认 64 秒一周；线内金色亮段仍带着渐暗长尾沿同一方向流动。底层曲线路径依照物品真实外轮廓保持固定，不对整个光效做平移或旋转。三段初始合计覆盖约 55% 的外轮廓弧长，绕行过程中保留大片空段，不形成整圈或均匀重复的麻绳式编织。每缕线的亮段约 3 像素宽（1080p），向尾部收窄、降低透明度；沿线有亮段、暗段与渐变色，只有亮段近侧附带很小范围的柔光。

仍只有外侧光线，没有贴物品边缘的基础内圈，也不描绘杯把等孔洞的内缘。三缕线使用独立曲率、长度和明暗相位，保留松散交错，避免三个平行圈或固定编织节距。物品外侧位置约 8 像素，曲线起伏约 7 像素，透明尾部可以稍向外逸出。

保持 1.35 秒淡入、0.55 秒消退和 4.8 秒轻微呼吸，呼吸幅度为 16%。光线在世界画面最终输出之后置顶合成；线条交错时使用独立深度，但不使用世界深度裁切。拾取仍受普通障碍、UI、失焦和输入阻断约束，已显示的光线在覆盖前景的同时自然消退。

## TA 边界

专用 Renderer 只响应带 `HoverGoldPointer` 的游戏摄像机，实验运行时临时使用独立管线，退出时恢复。正式画室、正式 Renderer 与 Build Settings 不变。

物品投影通过独立几何遮罩异步读回；只在初次预热或目标／摄像机投影变化时重新采集，读回后释放临时纹理。追踪二值遮罩的闭合边界，保留外部轮廓、排除被外轮廓包围的孔洞；轮廓平滑和弧长采样被缓存，不逐帧读回。当前采集宽度上限 1024 像素。

沿缓存外轮廓生成三条平滑闭合路径，只显示各路径上的一个局部金丝片段。初始片段保留原有松散曲率，原片段外的轨迹平滑延续并闭合，避免金丝前进到原空段后出现断路。每缕偏移后的曲线计算实际弧长，屏幕轮廓的有向面积统一顺时针坐标。

Shader 同时推进金丝片段的可见范围、两端渐隐及线内明暗。`StrandLapSeconds` 默认 64 秒，控制整段金丝的一周绕行；`FlowSpeedAt1080` 默认 22 像素／秒，控制线内流光，间隔约 96 像素。两种运动分别设置。网格只在轮廓、摄像机或造型参数变化时重建，时间不进入底层轨迹位置、曲率或穿插深度。暂停时金丝绕行、线内流光、呼吸和悬停渐变一起停下。

游丝使用单独的颜色和深度缓冲处理偶尔交错，然后以预乘透明度置顶合成，共两个常驻渲染 Pass；旧距离场传播、多圈柔光和整圈周期编织代码已移除。只存在几何缓存时不排入发光 Pass。摄像机或物品变化后异步刷新可能有数帧延迟，当前固定镜头实验未将此认定为正式近景切换验收。

遮罩不采样原材质的 alpha 裁切、不支持材质专属顶点变形／消隐。玻璃按几何体积采集。正式接入前还需要由现有交互系统提供“当前允许交互”的目标，排除未揭示房间／天空／隐藏物品，并审核视觉集合及镜头切换时的缓存刷新。当前实验不发送调查或收集命令，不写世界事实。
