# 悬停金光实验

日期：2026-10-14。当前阶段仅做 TA 与美术可行性验证，未接入 `AtelierPlayable` 或 `AtelierNight`。

## 美术目标与方案评估

最新参考使用内置生图工具重新生成，文件为 `Logs/HoverGold/Reference/疏松断续金色游丝参考.png`，原始提示词在同目录的 `疏松游丝生成说明.md`。先前密集、闭合的编织参考已弃用；这些图都只作美术方向参考，不导入运行时或 Git。

当前效果是在物品外侧浮现三缕松散的局部游丝，各自缓慢弯曲、漂移，偶尔交错。三段合计最多覆盖约 55% 的外轮廓弧长，至少保留约 45% 空段，不再形成整圈或均匀重复的麻绳式编织。每缕线的亮段约 3 像素宽（1080p），向尾部收窄、降低透明度；沿线有亮段、暗段与渐变色，只有亮段近侧附带很小范围的柔光。

仍只有外侧光线，没有贴物品边缘的基础内圈，也不描绘杯把等孔洞的内缘。三缕线使用独立曲率、长度和明暗相位，保留松散交错，避免三个平行圈或固定编织节距。物品外侧位置约 8 像素，曲线起伏约 7 像素，透明尾部可以稍向外逸出。

保持 1.35 秒淡入、0.55 秒消退和 4.8 秒轻微呼吸，呼吸幅度为 16%。光线在世界画面最终输出之后置顶合成；线条交错时使用独立深度，但不使用世界深度裁切。拾取仍受普通障碍、UI、失焦和输入阻断约束，已显示的光线在覆盖前景的同时自然消退。

## TA 边界

专用 Renderer 只响应带 `HoverGoldPointer` 的游戏摄像机，实验运行时临时使用独立管线，退出时恢复。正式画室、正式 Renderer 与 Build Settings 不变。

物品投影通过独立几何遮罩异步读回；只在初次预热或目标／摄像机投影变化时重新采集，读回后释放临时纹理。追踪二值遮罩的闭合边界，保留外部轮廓、排除被外轮廓包围的孔洞；轮廓平滑和弧长采样被缓存，不逐帧读回。当前采集宽度上限 1024 像素。

悬停期间沿缓存外轮廓生成三个局部游丝片段。游丝使用单独的颜色和深度缓冲处理偶尔交错，然后以预乘透明度置顶合成，共两个常驻渲染 Pass；旧距离场传播、多圈柔光和整圈周期编织代码已移除。只存在几何缓存时不排入发光 Pass。摄像机或物品变化后异步刷新可能有数帧延迟，当前固定镜头实验未将此认定为正式近景切换验收。

遮罩不采样原材质的 alpha 裁切、不支持材质专属顶点变形／消隐。玻璃按几何体积采集。正式接入前还需要由现有交互系统提供“当前允许交互”的目标，排除未揭示房间／天空／隐藏物品，并审核视觉集合及镜头切换时的缓存刷新。当前实验不发送调查或收集命令，不写世界事实。

## 首轮验证

Unity 6000.6.3f1 / URP 17.6.0，在本机 macOS Metal 下完成以下检查：

- C# 编译成功，最终编译无错误、无警告；Shader 编译无错误。
- 编辑器实际运行并采集 2560×1440 截图。陶杯、书、油灯从约 0.09 权重开始，继续浮现到约 0.48，再到完整轮廓；移开后从当前权重消退。
- 最终独立 macOS 构建成功，0 错误、1 警告，约 190 MB。警告为 Pipeline 未配置播放器服务；本实验无需播放器远程控制服务。
- 实际播放器分别采集 1920×1080 与 1280×720 截图。运行日志未出现异常、Shader 错误或警告；小窗口下仍为细线，未见宽光晕。
- 立板阻断射线，挡住的轮廓没有透过立板；立板切口没有新增金线。自动采集的快速划过结束帧与无悬停帧一致。
- 小窗口播放器检查了已悬停时输入阻断、连续切换和禁用目标。切换时旧物品权重约 0.70、新物品约 0.06，禁用后没有残留轮廓。
- 录制 288 帧真实渲染，编码为 24 fps、12 秒预览 `Logs/HoverGold/悬停金光_真实运行预览.mp4`。采集采用固定模拟步长，仅用来展示渐变与流光，不代表性能测量。
- 正式两个画室场景、正式 Renderer 与 Build Settings 没有变更；构建引起的自动序列化回写已恢复。原有 `QualitySettings.asset` 修改保留。

取证目录为 `Logs/HoverGold/EditorCapture2`、`Player1080`、`Player720` 和 `FilmFramesFinal`。复现静帧采集可向独立播放器传入 `--hover-gold-check <目录>`；逐帧预览使用 `--hover-gold-film <目录>`，两者均为自动坐标。

初步判断：这种细线流光适合继续审美评审，能表达“整物、缓慢、内敛”的悬停提示。尚未做真人鼠标／审美验收、GPU 性能定量测量、与正式画室 Painterly／曝光的组合运行验证，也没有承诺 alpha 裁切物品可直接接入；这些是下一阶段具体接入时的检查项。

## 第二轮提亮、呼吸与线宽调整

- 根据用户反馈，将主线宽从 1.05 提至 1.4 像素，最大混合权重从 0.28 提至 0.40，并把金色调亮。保留 1.35 秒淡入、0.55 秒消退及 10.5 秒流光周期。
- 新增 4.8 秒周期、22% 幅度的平滑呼吸。只改变金线亮度，最低为峰值的 78%，不会熄灭或改变物品表面。暂停仍使用同一受暂停影响的时间。
- C# 与 Shader 检查通过，Shader 消息为空；专用 Renderer 资产通过 Editor API 同步，生成器也使用相同参数。
- 更新独立 macOS 预览包，构建成功、0 错误、3 警告。警告为 Pipeline 播放器服务未配置，以及两个未使用的 Core 调试遮挡 Shader 被裁剪。实际播放器运行日志没有异常、Shader 错误或警告。
- 在 1920×1080 实际播放器采集 384 帧，陶杯停留八秒，覆盖完整呼吸周期。已观察亮度缓慢升降、略粗轮廓和最终消退；结束帧与无悬停帧一致。取证位于 `Logs/HoverGold/FilmFramesBreathing` 和 `呼吸轮廓观察.txt`，16 秒视频为 `Logs/HoverGold/悬停金光_提亮与呼吸预览.mp4`。
- 本轮仍只调整独立测试资源，未接入正式画室；自动坐标采集不视为真人鼠标验收。

## 第三轮三像素主体与多缕渐变 VFX

- 用户要求从简单线条升级为柔和的多缕金光，并将主体轮廓提高到约 3 像素。实现新增轮廓种子与最近轮廓传播，再分别绘制三缕具有不同偏移、宽窄、波动与软尾的光带。
- 保留原有淡入、消退和呼吸；光带采用加法合成，亮处带暖白金，沿光带横向和末端平滑渐隐。最大展开范围是 VFX 外缕范围，不是把主轮廓加粗到该宽度。
- 编译与 Shader 检查通过。编辑器运行检查了淡入／消退、快速划过、切换、禁用、输入阻断和立板遮挡；没有新增 Console 错误。遮挡射线阻断，立板切口未出现金线。
- 最终独立 macOS 构建成功，0 错误、3 条工具／Core 调试 Shader 警告。实际 1920×1080 播放器采集 384 帧，运行日志没有异常或 Shader 错误；结束帧与无悬停帧一致。
- 最终取证位于 `Logs/HoverGold/FilmFramesMultiWispFinal`。完整 16 秒实录为 `Logs/HoverGold/悬停金光_三缕渐变流光.mp4`；`三缕渐变流光_陶杯局部.mp4` 是同一实录的 420×400 像素裁切，未放大、未追加光效，便于查看光缕与渐变。素材均位于忽略目录。
- 这是基于真实物品轮廓的屏幕空间程序化 VFX。尚未接入主场景，也没有把自动采集视为真人鼠标或最终美术验收。
