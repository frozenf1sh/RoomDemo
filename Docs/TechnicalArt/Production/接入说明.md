# 绘画效果生产接入

只整理已通过的绘画、星夜、杯水与擦开算法；资源与演示均独立，未接正式画室或游戏路线。Unity 6000.6.3f1 / URP 17.6.0。

主 Editor 正在正式场景 Play 时，退出 Play 后刷新 Assets，再执行下面步骤；当前验证在隔离工作树完成。

**接入三步**

1. 在 Project 中选择主摄像机实际使用的 `Universal Renderer Data`，执行 `游戏 → 技术美术 → 生产接入 → 给所选 URP Renderer 安装绘画 Feature`。保留其他 Feature；不替换全局 Pipeline。
2. 选择主摄像机，执行同菜单的 `给所选摄像机安装控制组件`。安装 TAA、深度／Opaque Texture、MSAA 关闭与四级资源。由主开发保存场景。Overlay Canvas 在效果之后绘制；World Space UI 使用独立 Overlay Camera，且不要给它添加 `PainterlyCamera`。
3. 从 `Assets/_Game/Content/TechnicalArt/Production/Prefabs/` 拖入需要的效果，给天空与局部组件调用 `BindCamera(camera)`。内部 Shader、Material、GPU 反馈与杯口／落点已经连好。杯水允许平移、转向和等比缩放；桌面对应 WetPatch 的水平面，落点由 LandingAnchor 调整。

运行时代码位于 `Game.RealtimePainterly` 程序集。调用方（例如 `Game.Unity.asmdef`）需要增加对它的引用；本轮没有修改其他 Agent 维护的 asmdef。命名空间为 `Game.Unity.TechnicalArt.RealtimePainterly.Production`。直接连接 UnityEvent 无需写调用代码。

| 组件 / Prefab | 公开入口 | Inspector 主要参数 |
|---|---|---|
| `PainterlyStyleController` / `PainterlyCameraRig` | `TransitionTo(stage, seconds)`、`SetPainterlyIntensity(0–1)`；`ShowReality/Touched/Dream/Final` | 四级 Profile、TransitionSeconds；同一算法强度 0.06 / 0.27 / 0.62 / 1 |
| `PainterlyLocalController` / `PainterlyLocalInfluence` | `SetTargets(Renderer[])`、`TransitionTo(intensity, seconds)`、`ExpandTo(extent, seconds)`、`Clear()` | Targets 指定物体；为空时用世界区域，MaximumRadii 以米计。局部与全局取最大值 |
| `LivingSkyController` / `LivingSky` | `SetRevealDirection(worldDirection)`、`RevealTo(coverage, seconds)`、`FlowTo(flow, seconds)`；`ShowLocal/StartFlow/ExpandFull/Hide` | Opacity、Feather、世界朝向；PanoramaRepeats 为整数。Coverage 0→1 为普通天空→局部→全天空 |
| `LivingWaterController` / `LivingWaterCup` | `SetState(Still/Swirl/Overflow/Stopped, seconds)`；`Swirl/StartOverflow/Stop`；`SetFlow/SetPigmentInjection/SetOverflow` | FlowStrength、PigmentInjection、TransitionSeconds；停止保留湿痕 |
| `PainterlyRewriteController` / `PainterlyRewritePanel` | `RewriteTo(amount, seconds)`、`SetRewrite`；`Open/Close` | 既有笔势裁剪面与 TransitionSeconds；后方放真实内容，不自动改碰撞 |

```csharp
style.TransitionTo(PainterlyStage.Touched, 3);
local.SetTargets(new[] { targetRenderer });
local.TransitionTo(.62f, 4);
sky.SetRevealDirection(window.forward);
sky.RevealTo(.16f, 5);
sky.FlowTo(1, 6);
water.SetState(LivingWaterState.Overflow, 2);
rewrite.RewriteTo(1, 6);
```

以上组件只消费表现指令，不读写 GameState，不自动串联事件。新渐变从当前值开始并中断旧目标；零秒与 `Set…` 用于立即恢复。暂停调用 `SetPaused(true)`；Sequence 手动采样时先暂停自动更新，再调用 `Advance(seconds)`。正常自动更新使用 `Time.deltaTime`。新游戏分别恢复 Reality／局部强度零，并调用天空、水、擦开的 `ResetEffect()`，取消旧演出并清除各自 GPU 历史。关闭效果根物体会释放它拥有的运行时 RT／流束网格。

**独立查看**：打开 `Production/Scenes/TechnicalArtProductionBenchmark.unity`，或运行 `Builds/TechnicalArtProduction/TechnicalArtProduction.app`。面板控制事件；Space 暂停、R 重置、C 慢转、H 隐藏 UI、Esc 退出。只有 Benchmark 临时使用独立 Pipeline，并在退出时恢复。生产 Prefab 不含 Benchmark 与十秒自动导演。生成器只写 Production 目录，存在未保存 Scene 时会拒绝生成。

边界：局部精准遮罩主要用于普通不透明 Renderer；透明、材质自带裁剪和顶点变形需要单独核对。天空显现不会自动改变环境光；主开发可另外调度现有灯光。快速相机运动、很薄的轮廓、大幅缩放及多摄像机堆栈需在实际机位再核对。既有 Shader / 许可在 `RealtimePainterly`、`LivingPainting`、`LivingMatter/Licenses` 与 `Assets/ThirdParty/PainterlyRendering`；木纹与字体来源沿用项目原记录，没有 AI 画作贴图。

**本轮实机验证**：独立工作树的 macOS Player 编译、渐变中断、暂停／零秒恢复、停水保留湿痕、重置、跨加载场景摄像机绑定和预设生命周期均通过。800×450 中文 UI 无截断。M5、1600×900、Final + 天空／杯水同时运行的五秒无截图采样，中位 16.667 ms / P95 17.568 ms（目标 60 fps）；这不是正式房间性能承诺。构建无错误，三条已有工具／调试 Shader 警告；运行有四条未使用景深／Panini Shader 被剥离的 URP 警告，无运行异常或绘画 Shader 编译错误。

[慢镜头录像](8秒_慢镜头锚定.mp4)冻结颜料以单独观察锚定；8 秒慢转 3.6°、平移 0.109 米。桌面和天空样区按世界位置重投影，最佳整数偏移均为 0，平均 RGB 差分别不超过 0.00244 / 0.00143。该检查只覆盖此机位和速度。实际 UI 与 Reality／局部／Final 截图及小型 JSON 数据在本目录。两份冻结核心 Shader、已通过的天空／杯水／擦开 Shader 与颜料模拟字节保持原值，未运行完整游戏路线测试。
