# 当前技术美术入口

当前版本是 **Painterly3DBenchmark**：普通 3D 场景通过实时 Kuwahara、世界空间笔触与 URP TAA 处理。

- 场景：`Assets/_Game/Content/Scenes/Painterly3DBenchmark.unity`
- 一页技术决策：`Docs/TechnicalArt/Realtime/技术决策.md`
- 独立 macOS 程序：`Builds/Painterly3DBenchmark/Painterly3DBenchmark.app`
- 运行图与环绕录像：`Docs/TechnicalArt/Realtime/`

打开场景后进入 Play。O / P 切换原图与绘画；空格环绕／冻结；左右键移动；D 查看世界锚点；H 隐藏面板。面板和 `PainterlyCamera.SetPainterlyIntensity(0～1)` 控制同一个强度。保持 RenderGraph，摄像机启用 TAA，MSAA 设为 1。

主开发可复用 `RealtimePainterly/Rendering/PainterlyBenchmarkRenderer.asset` 和 `RealtimePainterlyFeature.asset`，给目标摄像机添加 `PainterlyCamera` 并绑定主光；参数仅属于 Unity 表现层。Shader 已通过资产引用保留在构建中，普通 Renderer 继续使用各自材质。

此前三个实验场景及参数 API 保留作历史实验，本轮不继续迭代它们。新版本尚未接入主房间；天空、反射和重写等后续效果等待此版本视觉确认。
