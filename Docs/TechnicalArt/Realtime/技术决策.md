# 实时绘画渲染：第一版技术决策

目标版本：Unity **6000.6.3f1 / URP 17.6 / RenderGraph**。本轮只做普通 3D 静物 Benchmark。

**A. 哪个项目直接复用**

复用 [GarrettGunnell/Post-Processing 的 AnisotropicKuwahara.shader](https://github.com/GarrettGunnell/Post-Processing/blob/871a7ffcc44174f237b4c0127db51026c438d7a4/Assets/Kuwahara%20Filter/AnisotropicKuwahara.shader) 的 MIT 算法代码；同时参考 [Josephy5 的 URP 参数与 Pass 接入](https://github.com/Josephy5/PostProcessing-URP/blob/96da10bcc1b5b8bf8df60caa3d71ca31305642ad/Assets/Kuwahara/Anisotropic%20Kuwahara/AnisotropicKuwaharaPass.cs)。不导入示例模型、不更换物体的普通 Lit 材质。时域稳定直接复用项目自带的 URP TAA。

**B. 哪个算法移植**

移植 Sobel RGB 梯度 → structure tensor → 可分离高斯平滑 → eigenvector / anisotropy → 八扇区多项式权重椭圆 Kuwahara；张量使用浮点格式，保留负交叉项和角度。移植 [tantaneity 的世界空间 Voronoi 色块与光照切向笔触思路](https://github.com/tantaneity/painterly-urp/blob/fa4961504203344b9f0d234f4ed45b72481cb218/Assets/Shaders/Strokes.shader)：固定世界种子，关闭逐帧 boil，笔触长度和宽度用世界单位，并拒绝跨深度／法线边界取色。该仓库无许可证，源码不复制。

**C. 哪些不适合直接接入**

Garrett 原 Pass 是 Built-in `OnRenderImage`；Josephy5 虽标 Unity 6，实际仍是 `Execute / cmd.Blit`，README 明确要求 Compatibility Mode，故改为 RenderGraph。tantaneity 的默认 jitter、屏幕 UV 高光尺寸和仅判断“不是天空”的取色保护，不满足本项目稳定性要求。[Impasto-Lab](https://github.com/Impasto-Lab/Painterly-Curved-Strokes/blob/b9412d7365c71f55e0397df8102ec023f4bcf32d/core/stroke.py) 是 Python 离线栅格器；已读 `painter.py / stroke.py / gradient.py`，本版不搬 CPU 逐笔绘制。[Hertzmann 原论文](https://mrl.cs.nyu.edu/publications/painterly98/hertzmann-siggraph98.pdf) 的由粗到细、沿梯度法线行进和误差终止，留给后续曲线笔触层。[Sagit](https://www.sagitsoftware.com/projects/oil-paint-shader/) 只公开技术说明，未找到可下载源码；不能声称已复用其 compute、relief 或 temporal blend 实现。

**D. 第一版 Benchmark pipeline**

普通 PBR 场景 → 原始 RGB 张量分析／方向场 → 世界空间 Voronoi 色块＋光照切向笔触 → 沿原始方向场的八扇区 Kuwahara 柔化 → 原图／绘画强度混合 → URP TAA → 色调映射。只从当前真实 3D 帧取色，无预生成画作、AI 图片、笔触贴图或滚动绘画纹理。独立场景放 sphere、cube、plant、wooden table、water plane、directional light；提供原图对照、冻结镜头、环绕镜头与世界色块调试。先交实际截图与移动镜头录像；美术接受仍由用户判断，之后才做天空、反射与重写。

运行入口与参数用法见 [短使用说明](../使用说明.md)。已完成 Unity 编译、真实 macOS 构建和 1600×900 原图／绘画截图；镜头录像按实际时间戳记录约 12 秒。构建 0 错误；最终增量构建仅剩项目已有的 Pipeline Runtime 配置缺失提示；播放器另保留未使用的景深／Panini Shader 剥离提示。没有运行全游戏流程测试，也不把技术检查当作美术接受。
