# 一幅画正在慢慢活过来

本目录保留上一轮实验记录。桌面蓝色 Ribbon 与旧 Final 星空已经弃用；冻结的 Painterly Renderer、四级档位、局部影响和笔势擦开仍保留。新天空与杯水请看 [LivingMatter 使用说明](../LivingMatter/使用说明.md)。

核心算法已在 `c154fba` 冻结；两份基础 Shader 不修改。新实验只增加局部合成和演出，尚未接入主场景。

| 档位 | 强度 | 用途 |
|---|---:|---|
| Reality | 0.06 | 初始现实，保留清晰的原材质 |
| Touched | 0.27 | 局部物体先被触碰 |
| Dream | 0.62 | 线周围逐渐进入绘画 |
| Final | 1.00 | 已通过的完整基础画风 |

场景：`LivingPaintingBenchmark.unity`、`PainterlyFinalHero.unity`。独立程序：`Builds/LivingPaintingBenchmark/LivingPaintingBenchmark.app`。

桌面默认播放 18 秒：静止 0–3 秒 → 流动 3–6 秒 → 点亮 6–10 秒 → 延伸 10–16 秒 → 局部传播 14–18 秒。传播完成以后线内颜料继续慢流，空格才冻结时间。全局一直保持 Reality；球体提前进入 Touched，线周围进入 Dream。打开按钮独立播放十秒的墙面擦开，淡颜料引导线与裁剪共用同一中心路径。星夜、水面与桌面通过 F 切换。

快捷键：1–4 对照四档，空格冻结，R 重播，O 打开，C 以 0.45°/秒转动镜头，H 隐藏面板，F 切换实验，Esc 退出。所有运动保持真实时间，录像不加速。

主开发可引用：

- `PainterlyStyleProfile.Apply(PainterlyCamera)` 或 `SetPainterlyIntensity`：全局权重。
- `PainterlyInfluence`：Targets 指定 Renderer；Targets 为空时使用世界轴对齐椭球，Radii 以米计。`SetPainterlyIntensity` 控制局部权重，最多 16 个区域。局部／全局取最大值，不累加。OnlyCamera 限制摄像机。普通透明物体、材质自带裁剪或顶点变形尚不属于精准遮罩支持范围。
- `LivingStroke.SetVisualState(Flow, Light, Extend, PainterlyIntensity)`：固定路径上的色泽流动、少量暖光、弧长末端生长。VisualTime 与 LightDistance 可由 Sequence 控制；AutomaticTime 可用于独立播放。PreserveOriginal 保护专门创作的细颜料线。
- `PainterlyOpening.SetRewrite(0–1)`：沿共享笔势裁去展示面的几何可见区域，实际显示后方模型。使用专用材质，普通物体保留各自材质。
- `LivingPainting/Rendering`：独立 URP renderer / feature，沿用 TAA 和 MSAA 1；新 Feature 只扩展最后的局部合成。

统一语法：**已有线内移动 → 光沿线经过 → 同一末端长出 → 同一笔势擦开表面**。轮廓和种子固定在世界／几何路径；其他表面保持静止。星夜采用三尺度三维短笔势与固定星点，只有三颗星光缓移；水面镜像重新渲染当前三维场景（15 Hz），波纹与星夜共用 VisualTime，最终由主摄像机统一绘画化，没有 AI 画作或预生成油画贴图。


验证：真实 macOS 构建的 18 秒桌面、10 秒擦开和 12 秒星夜录像，以及四档同机位截图均在本目录。镜头以 0.45°/秒转动；五个视角的桌面世界锚点重投影，最佳整数偏移均为 0，平均 RGB 差约 0.008。该结果只覆盖当前空白桌面区域和 5.4° 的旋转范围，屏幕尺寸固定的 Kuwahara 核在快速转动、薄轮廓或大幅缩放时仍需复查。

一次项目流水线：编译、场景校验、EditMode 59/59、PlayMode 29/29、构建通过。随后只修正了表现层终帧时钟、中文面板高度，以及完整墙体的局部擦开几何与取景、星夜与水面的共享时钟；再次编译、真实构建与 Console 检查。独立构建有三条已有工具／URP 警告（未启用 Player Pipeline、两个未使用调试 Shader 被剥离），最终独立构建未出现 Shader 编译错误或运行异常。主场景、全局管线配置和既有核心 Shader 哈希保持原值。
