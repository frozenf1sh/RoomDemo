# 颜料天空与杯水 Hero

这轮替换旧桌面 Ribbon 与旧 Final 星空，只做两个独立效果。冻结的 Painterly Renderer、四级档位、局部影响与笔势擦开保持原样；未接主房间或游戏路线。

- [15 秒纯天空](15秒_活着的星夜.mp4)：三个主旋涡、蓝紫色颜料与暖星。固定镜头，颜料与笔触持续演变。
- [10 秒杯水](10秒_杯水与颜料.mp4)：静水 → 液面流动 → 两股颜料卷入 → 接触杯沿 → 落水与不规则湿痕。木纹保留。

打开 `Builds/LivingMatterHeroes/LivingMatterHeroes.app`。空格暂停／继续，R 清除颜料历史并重播，F 在两个 Hero 间切换，Esc 退出。Unity 场景位于 `Assets/_Game/Content/Scenes/Experiments/TechnicalArt/`：`LivingStarryNightHero.unity`、`LivingWaterPigmentHero.unity`；无常驻开发界面。

资源在 `Assets/_Game/Content/TechnicalArt/LivingMatter/`。天空使用 1024×576 ARGBHalf 反馈颜料；杯内与桌面各 512×512。RK2 反追踪、MacCormack 校正与限制器以 30 Hz 更新实际历史状态。作者布置的旋涡与流函数旋度控制构图；暖星颜色进入附近颜料。当前冻结 Renderer 对实时结果绘画化，没有导入油画或 AI 图片。

主开发可直接用 `GpuPigment.Flow` 调流速、`Injection` 调局部注入；`AutomaticTime=false` 后由 `Advance(seconds)` 推进，`ResetPigment()` 清除历史。桌面湿膜通过 `Feed` 接收杯内实时浓度。`LivingWaterPigment.Advance` 同步自由液面、圆截面落水与湿膜，`ResetWater` 重播；全局画风仍用现有 `PainterlyCamera.PainterlyIntensity`。当前两个场景为固定构图的 Hero，尚未接主场景。

算法参考与原文许可见资源的 `Licenses/来源.txt`、`PavelDobryakov-MIT.txt`。实际阅读了 [WebGL-Fluid-Simulation 的 Shader 与 step()](https://github.com/PavelDoGreat/WebGL-Fluid-Simulation/blob/a2d292931f19d9b3b9f564e23e6c32729d2121c3/script.js)、[GPU Gems 3 第 30 章](https://developer.nvidia.com/gpugems/gpugems3/part-v-physics-simulation/chapter-30-real-time-simulation-and-rendering-3d-fluids)。本效果是颜料平流与液体形态近似，未实现完整压力流体求解器。

最后统一检查：Unity 6000.6.3f1 / URP 17.6.0，真实 macOS Player，Apple M5 / 16 GB，1600×900。无截图写盘的五秒采样：天空中位 17.805 ms / P95 18.498 ms，杯水中位 16.833 ms / P95 18.835 ms。录像为真实时间的 24 fps 输出；固定镜头，无速度加工。编译与运行没有错误；构建保留三条已有工具／URP 警告（工具的 RuntimePipeline 未配置、两份未使用的遮挡调试 Shader 被剥离）。未跑完整游戏测试；基础两份 Shader、擦开、主房间和原全局管线配置的 SHA-256 均保持原值。
