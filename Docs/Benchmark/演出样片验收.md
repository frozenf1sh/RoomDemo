# 海画涌现演出样片

目标是让玩家只组合「海 + 画」，随后看见水进入现实，旧植物与窗外自行回应。领域规则和发现条件保持原样；演出节奏只存在于 Unity 表现层。

## 基线

- 2026-10-04：编译、34 项编辑模式测试、9 项运行模式测试、场景校验与 macOS 构建通过。
- 初始独立试玩截图见 `基线_初始房间.png`；领域涌现预设截图见 `基线_涌现与性能.png`。
- 基线现象：海画、水滴、水生植物和海窗几乎同时开始变化，难以读出扩散因果。
- 编辑器运行模式，844 × 451，5 秒采样：平均 60.1 帧/秒，帧时间第 99 百分位约 19.9 毫秒，发生 5 次第零代回收。这个结果包含编辑器开销，不能用于宣称独立程序或普通 PC 性能。
- 离线机位截图用于比较空间摆放，编辑模式下可同时看见多个状态层；它不代表新游戏状态。

## 当前构图与光照

- 桌椅退到右侧，画框底部的滴水路径与落点保持可见。
- 盆栽、画、窗户保留独立视觉空间，固定观察机位仍允许玩家自由转头。
- 光照脚本分为暖灰初始、远方自然光、局部海光与涌现终态。海光只通过表现进度扩大。
- 场景增量工具拒绝覆盖未保存的调整，保留原有 Prefab 身份与稳定 ID。

## 真人评审

最终样片必须由至少一名未参与实现的人试玩，不能用自动测试代替。

1. 从「海的解释之前」开始，执行「海 + 画」，观察画、水、植物、窗外四个独立节拍。
2. 不提前讲解原因，询问「你觉得植物为什么后来变了？」。
3. 询问「刚才哪些变化是你直接做的，哪些不是？」。
4. 记录是否注意到第一滴水、植物性质变化和窗外变化，以及是否感到意义正在扩散。

真人理解度与 60～90 秒观察段的情绪曲线目前待验收；自动化只验证功能、时序和恢复。
