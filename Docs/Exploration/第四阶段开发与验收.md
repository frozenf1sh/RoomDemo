# 第四阶段：探索与世界重构

本阶段的代码、场景与自动功能验证已完成。陌生玩家理解度、鼠标手感、首次时长和音效听感仍待真人试玩，不能把技术复测记录当成该阶段全部人工验收通过。

## 两个实现案例

### 生长来自观察

从全新会话开始，房间左键点击盆栽只认识盆栽，随后进入独立近景复制体。左键拖转、滚轮拉近，转到背面才可亲点土边新芽；没有永久黄色描边。
旧书第一天就可拿近，封面打开、三页有限状态、页角翻页、短句亲点、轻勾线、纸页声音。第二页“向光”提供第二个观察。

笔记本区分看见的事物、记下的细节和想出的意义，保留三个组合槽：

```text
新芽 + 向光 → 线索：生长
生长 + 盆栽 → 事实：plant.starts_growing
结束今天 → 第 2 天 → plant.overgrown → plant.grown → book.fallen
```

第一种配方留在笔记里，以连接和大字书写奖励联想；第二种收起笔记并让房间当天轻微舒展。
结束今天由玩家主动选择。约 2.4 秒淡出、黑屏余音、淡入后，植物繁茂且书落到地面；到期事实已经在提交日序命令时计算，黑屏只延后表现。

第二天书中第三页可亲点地平线获得远方，继续旧窗景、风、纸、海画链。
窗户与画仍必须分别亲点；纸张或书的指引不替玩家授予它们。新发现有通知与未读按钮脉冲，打开笔记停止闪烁。检视时通知移到右侧，保留中央阅读区域。

### 星空世界重构

星空是独立开发样板，没有加入主流程新谜题。F7“提交星空事实并播放”通过应用层提交已声明的 `world.starry`；导演只是事实消费者。“仅预览”不添加事实。

| 时间 | 表现节拍 |
| --- | --- |
| 0～1 秒 | 风声压低，房间安静下来 |
| 1～3.8 秒 | 天花板升起、退去，完整星空显露 |
| 4～6.7 秒 | 后墙消失，左右墙退向两侧 |
| 6～8 秒 | 窗视觉扩大、退去，窗失去边界 |
| 8～10 秒 | 原地板换为保留木台，草地、树与岩石显现 |
| 10～11.5 秒 | 运行时生成一个篝火并点亮 |
| 11.5～15 秒 | 夜色、雾、灯光和环境声音完成整体过渡 |

家具留在原地，使用同一个场景，没有关卡硬切。原生复测检查天花板／后墙／旧窗边界消失、自然外景与星空出现、只有一个篝火，以及桌、椅、书架、画架的世界位置不变。

## 结构与边界

| 层 | 本阶段职责 |
| --- | --- |
| 领域 | 统一线索分类、配方产出线索／事实、世界条件发现、显式日序和待执行效果 |
| 应用 | GameSession 命令入口；普通 C# 有限检视状态表，不拥有视觉 |
| Unity 适配 | 房间输入、近景复制体、相机与热点、书页视觉、笔记反馈、跨日黑屏 |
| Unity 表现 | 独立建筑模块、外景、世界变换、薄主题、具体星空导演与生成物清理 |
| Editor | 增量安装、单件模型导入、引用与场景校验、保护美术场景的 CLI 构建 |

`SemanticRecipe` 同时支持 `ProducesClues` 和 `ProducesFacts`，保持无序精确二元／三元匹配；灵感与解释没有两个引擎。
只有配置和对应 Presenter 含具体内容，RuleEngine 没有新芽、海、窗、天空的特判。
物体产出校验拒绝配方直接给物体、细节给物体或一个来源赠送另一个物体；明确调试预设另行处理。

待执行反应用反应身份去重，登记时复制输出，到达日序后先移除再应用正式事实闭包；不会重复产生 BookFallen。
没有真实时钟、四天剧情、存档、失败期限、物理抓取、纸张模拟、自由节点图或自然语言解析。

房间地板、天花板、后墙、左右墙与窗视觉均独立。窗继续分框、近景、远景／海景、窗帘与特效。
`WorldMutation` 提供显隐、替换、按槽生成、位移、旋转、缩放、共享材质属性块和主题过渡；它不持有 GameSession，也不写领域。
主题只管理环境光、雾、灯、整体风格参数与环境声音。固定外景不是过程生成，火焰不使用流体模拟。

检视、跨日和两套导演都有取消／恢复行为。最终预设即时恢复，不重播前一天；重开释放输入锁、相机、节点姿态、材质块、灯光音量并清理篝火。
项目 82 个自有 C# 文件均具备中文职责文件头与代码内中文行注释；关键状态、输入和变换 API 补充 XML 文档。

## 内容与调试

新增两个观察，正式内容为九个可收集线索、四条配方、十条反应（含次日登记及成熟兼容反应）。仅盆栽与书有深度检视；其他核心对象仍走房间调查。
环境补充书堆、旧箱、落地灯、失败草稿、画管和瓶子，不把每件装饰变成游戏实体。

新增小型 FBX 来自 [Kenney Furniture Kit](https://kenney.nl/assets/furniture-kit) 与 [Nature Kit](https://kenney.nl/assets/nature-kit)，2026-10-04 已逐项核查官方 CC0 页面。仅导入七个新增小网格，模型不包含玩法逻辑，统一项目材质。
原始许可、来源、大小、下载日期与用途见 [资源登记](../../Assets/ThirdParty/LICENSES.md)。近景书本、新芽、星空图案、尖火焰网格和合成占位音为项目原创。

默认玩家模式无开发 F 键和常驻物体标签。原生启动用 `-roomDemoDevelopment`，Editor 勾选 GameBootstrap 的开发模式后开放：

- F3：领域状态、添加事实、重置、授予全部和预设。
- F4：海画独立表现预览；F6 跳到海画前；F8 切换取样窗口。
- F7：星空真实触发／只读预览／重置／恢复／前置与终态／直接检视。
- F9／F10：旧海画技术复测／取样；不在正式玩家模式开放。

七个新预设为 `Start`、`BeforeGrowthInsight`、`GrowthUnlocked`、`BeforeDayAdvance`、`AfterGrowthDay`、`BeforeStarryWorld`、`StarryWorldFinal`；海画 `BeforeSea`／`Emergence` 保留并适配次日状态。

## 已知限制与真人验收

构建保留 Unity 包级提示：发行版未配置运行时 Pipeline，以及两个内部遮挡调试 Shader 裁剪。原生日志另提示 URP 景深和 Panini Shader 在当前已有配置下裁剪，相应后处理通道停用；没有以改变无关渲染配置来掩盖这些提示。
占位音是合成音效，视觉为统一低多边形原型。本阶段技术验证不证明最终美术品质、音效听感或“像艺术家获得灵感”的玩家心理体验。

桌面在复测时处于锁屏状态，当前没有有效陌生玩家评审。不能把自动路径称为人工试玩，也不填写虚构首次时长。
请依 [真人试玩记录](../PLAYTEST.md) 询问：

1. 生长这个想法是哪里来的？
2. 一天过去以后，你期待发生什么？
3. 星空出现时，你觉得是换关了吗？

预期回答应体现两处观察的联系、时间后的持续影响，以及同一房间打开为新世界。答卷仍待实际采集，因此第四阶段完整人工 Definition of Done 尚未关闭。
