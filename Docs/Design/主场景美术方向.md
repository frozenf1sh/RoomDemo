# 主场景美术方向

画室保持可读、安静、有真实材料感。暖灯照亮工作区，窗外的冷色夜景提供纵深。桌面物件要能看清，也要能参与观察、绘画和后续变化。

屋顶打开后，星夜在同一画面里逐渐显露并持续流动；不要切换成另一套画风。木、灰泥、玻璃、纸和织物保留各自质感，笔触只改变被影响的区域。
