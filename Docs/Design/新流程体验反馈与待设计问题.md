# 新流程体验反馈与待设计问题

> **记录状态：玩家意见整理稿。** 本文记录当前反馈、已核对的实现状态和后续需要回答的问题，不是已定稿的玩法方案，也不要求立即保留或实现现有交互。新流程策划案尚未完成，具体阶段、合成词与资产的重新映射留待下一步。
>
> 记录日期：2026-10-16

## 一、核心意见

现有流程最需要优先解决的问题，是玩家很难把获得的抽象性质联想到具体的现实物品和可执行动作。

- “流动”勉强会让人想到水杯，但联想仍不稳定。
- “点亮”和“打开”没有清楚指向玩家接下来应该操作哪件现实物品。
- “擦除”更难让人想到屋顶；玩家没有理由自然推断要把它用于建筑表面。
- 如果关键玩法依赖玩家猜中“性质词＋现实物品”，单靠自由探索和配方尝试不足以让多数玩家发现它。

洗笔、点灯、拉帘，以及“流动、点亮、打开、擦除”这些动作和词条都可以重新评估。它们不是必须保留的既定内容。后续应结合新流程最终确定的合成词语与资产，重新判断哪些现实操作能让玩家自然理解、亲手尝试，并立即看懂结果。

## 二、模块：现实交互与性质词的联想

### 玩家反馈

我很难从目前获得的词语推断应该把它用到什么现实物品上。洗笔后想到水杯已经算比较勉强；“点亮”“打开”没有明确的现实目标；“擦除”用于屋顶更是几乎无法预料。

### 设计问题

当前词语表达的是宽泛概念，现实交互却要求玩家把概念映射到一个具体对象，再猜测它能产生什么变化。候选物品、词语和结果之间的因果提示不够明确，导致探索像猜配方。

### 后续要求

- 对每个新合成词，明确记录玩家可能联想到的现实目标和可尝试动作。
- 如果没有足够自然的联想，就调整词语、目标物品、动作或结果，不把“玩家应该猜到”作为前提。
- 交互的提示需要帮助玩家发现可尝试的方向，同时保留玩家亲手提交和观察结果的过程。
- 不预先限定旧有洗笔、点灯、拉帘、擦除动作必须进入新流程。

## 三、模块：动作完成后自动获得关键观察

### 玩家反馈

洗完笔之后，我基本想不到还要再点一下水面，才能得到洗笔后颜料散开的性质。完成一个明确操作后，应该直接记录这个操作造成的、玩家确实看见的变化，不要再要求玩家额外点击同一个物件来领取观察。

### 对洗笔流程的具体意见

如果玩家完成洗笔，且画面已经表现出颜料散开，应在洗笔完成时自动获得相应性质观察，例如“散开的颜料”或最终策划案确定的名称。之后如果已有足够材料解释这个变化，就应触发相应灵感提示。

这条意见是针对“动作已经完成、结果也已呈现，却还要重复点击领取线索”的额外步骤，不代表所有动画都应自动授予任意线索。获得什么应与真实完成的动作及其可见结果一致。

### 当前实现核对

当前主线里，洗笔动作会记录 `Washed` 并播放笔尖接触、注色和水纹表现；“散开的水纹”观察仍要玩家之后再次点击水面才会记入。该观察依赖 `Washed` 前置事实。对应输入逻辑见 `AtelierGameplay` 的洗笔和水面分支，观察定义见 `AtelierRules`。

因此，当前实现确实保留了这一步额外点击，和本反馈指出的问题一致。若后续决定洗笔完成即获得观察，应由已完成的洗笔交互及其结果触发对应观察，不再要求第二次点水。

## 四、模块：明确显示新形成的灵感

### 玩家反馈

当玩家已经获得足以解释某个变化的性质时，应明确告诉玩家笔记本里出现了新的灵感，让玩家知道这些材料之间存在值得继续思考的关系。现在我不确定系统是否已经这样实现，也不确定提示是否足够明显。

### 当前实现核对

当前系统已经有“灵感”机制：当规定的观察碎片全部被玩家知道后，领域规则会自动发现对应灵感；打开笔记本后，右侧灵感区会显示类似“灵感·流动”的条目。新碎片也会显示短暂发现提示；笔记本关闭时，小型“笔记 · N”提醒会提示有未读发现。

但这些机制目前有几个边界：

1. 灵感出现的前提是相关观察碎片已经获得；洗笔之后仍需再次点击水面，才能取得“散开的水纹”，所以灵感也被这一步卡住。
2. 笔记本显示灵感，不等于明确告诉玩家下一步可尝试哪个现实对象。
3. 现有通用提示文案较概括，可能不足以让玩家理解词条间的联系或现实应用方向。
4. 获得灵感、把观察合成为“流动／点亮／打开”等概念、再把概念用于目标物品，是不同步骤；界面需要让玩家看清当前完成到哪一步。

相关实现位置：`RuleEngine.EvaluateLogics` 在所需碎片齐全后自动发现灵感；`NotebookView` 将已获得的灵感显示在右侧，并管理未读发现提示和通用探索提示。

### 后续需要确认

- 关键动作结束并自动获得观察后，是否立即触发对应灵感发现。
- 灵感发现时，笔记本提醒是否需要更明确地标示“新灵感”，并在打开后突出新条目。
- 是否提供轻量的下一步方向提示，使玩家知道可以试哪个现实对象；提示强度需要在明确引导和保留探索之间确定。

## 五、模块：现实变化必须立即可见且足够明显

### 玩家反馈

所有对现实场景的改变都应该在玩家提交操作后立即发生，并且效果要足够明显。当前把“流动”用于水面时，我觉得变化不明显，玩家可能看不出概念应用成功，也不容易理解这个词和结果的关系。

### 对“流动”的表现方向

“流动”可以重新考虑用于什么对象，也可以调整表现强度。可以研究更明确、与写实房间有明显区分的水面 Shader 表现，例如增强颜料流动、水纹范围，甚至让颜料溢出杯沿。以上是待评估方向，不是已经定稿的效果。

### 后续统一要求

- 提交成功后，变化应立即开始，不让玩家等待很久才看到因果结果。
- 结果应足以和变化前区分，且尽量让玩家看出“哪个词作用在了哪个物件上”。
- 如果效果需要持续演变，也应先给出清楚的即时反馈，再进入持续变化。
- 对写实场景做明显超现实改变时，可以明确建立风格差异，避免把关键反馈藏在很轻微的材质变化里。
- 需要评估效果在当前镜头尺度、房间光照和物件材质下的可读性；只在近景明显的变化，不能默认在主镜头也容易察觉。

## 六、模块：允许重新设计现有动作和资产映射

新流程案仍未完成，现阶段不应把旧互动当作必须保留的清单。待新案补齐后，可以从最新的合成词语、物件资产和阶段变化出发，重新判断：

- 哪些旧交互确实能帮助理解新词语；
- 哪些旧交互需要改造后才能成为有意义的现实实验；
- 哪些交互可以删除；
- 哪些新的现实对象和操作更适合表现该性质；
- 每种性质作用后应出现怎样直接、明显且可解释的变化。

尤其不能因为现有玩法已经有“流动、点亮、打开、擦除”，就默认它们与杯子、油灯、窗帘、屋顶的对应关系已经成立。需要重新从玩家能否联想和看懂结果来评估。

## 七、下一步评审清单

新流程策划案补齐后，对每个阶段逐项回答：

1. 玩家通过什么实际动作获得性质观察？动作完成后是否自动记录观察？
2. 玩家从所得词语能否推测至少一个可尝试的现实目标？如果不能，提供什么线索或调整什么设计？
3. 相关材料齐全时，灵感如何出现、如何提示玩家查看？
4. 玩家提交概念与现实物品后，是否立即出现足够明显的结果？
5. 结果在主镜头和目标近景中是否都可辨认？
6. 这项互动是新流程必要内容、可复用内容、需要重做的内容，还是可以删除？

在新案完整前，本记录不指定替代方案，也不把上述例子视为最终资产或技术实现要求。
