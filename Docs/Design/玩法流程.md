# 玩法流程

## 体验主轴

玩家先观察物件和变化，再把前后状态记进笔记本，组合出一种画法。画法既能完成画，也能作用于真实画室。选择通过行动发生，不弹出路线选择框。

## 共同开场

1. 面前是空白亚麻画布。先读桌上的便条：明早交稿，三个题目都画不下去，决定画眼前这些。
2. 亲点杯沿画笔，再逐件选杯、笔、桌上主灯和窗景，回画布落笔。每选一样就可以画一样，不需要先调查齐全部物件。杯、笔支持拉近检视；便条支持放大阅读。
3. 四项静物画齐后，旁白觉得水面太死，提示洗笔换色。近看杯水，再点实体画笔让笔毛碰水；没有洗笔按钮。比较平静水面和洗后散开的水纹，观察必须分别点击取得。
4. 按 `N` 打开笔记本，把两条观察拖到右页并提交，形成“流动”。回到刚画出的杯子，亲点画里的水，再将“流动”用于它，第一次点睛才让画中水纹持续变化。
5. 看左侧未点燃的油灯：玻璃罩原本就搁在旁边。亲点纸盒取火柴，点盒侧砂纸划亮，再将火柴头送到灯芯附近并点击。火柴会熄灭，可以重新划；点灯不会自动学会“点亮”。再亲点稳定的火苗，把熄灭与亮起的灯芯记在一起，提交比较才得到“点亮”。亲点画里的灯，给它添上这一点亮色。

当前落笔是固定静物构图的有限手势：拖一笔或点三笔完成选中物件，不是自由绘画。普通静物落笔不计入连续服从；便条、动画或配方都不能代替玩家取得其他物体。

## 两条路线

- **完成画作**：把学到的画法用于画里的水、灯和窗帘。画完成后由玩家主动交稿，画室保持原样。
- **改变现实**：把同一画法用于杯水、湿色和屋顶。流动与点亮共同改变天空；看见贯通画布与房间的笔迹后，玩家亲自调查整间画室，再决定是否擦去整个房间。

擦窗框和让水发光是可选实验，不是进入结尾的钥匙。房间不能开局获得；满足可见条件后仍需玩家亲点。星夜由运行时程序化笔触生成，不使用静态星空图。

## 实现状态

`AtelierPlayable` 是这条新路线的本机开发入口。空白画布、逐件落笔、实体洗笔、画中水纹，以及实体火柴点灯、前后比较和画中灯添色已通过本机独立构建观察。笔记摆词使用显式 UI 事件回放，真人拖拽与首次理解度尚未验收。火柴仍缺手部与接触声音。

`AtelierRules` 已列出部分后续规则，但窗帘、屋顶、天空和结尾仍要逐项核对场景输入、表现和实际运行；规则表存在不等于该段已经交付。

正式 Build Settings 继续只启用已认可的 `AtelierNight` 美术场景。新玩法副本不覆盖该场景，也不自动改正式入口。后续实施与验证见[画室玩法实施记录](画室玩法实施记录.md)。
