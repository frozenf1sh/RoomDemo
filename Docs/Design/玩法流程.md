# 玩法流程与双线操作攻略

本文对应 `Assets/_Game/Content/Scenes/AtelierPlayable.unity`。从同一个空白画布开局，完成画内的三次点睛可以定稿；把画法用于真实物体，就会走向擦开画室。路线由玩家实际操作形成，没有选路线的弹窗。正式 Build Settings 仍只启用 `AtelierNight.unity`，开发副本不覆盖认可的美术场景。

## 操作与笔记本

| 操作 | 实际效果 |
| --- | --- |
| 左键点实物 | 调查命中的实物；杯、画布、油灯、窗帘、湿色板会进入相应近景 |
| 近景中右键，或“返回画室” | 回到原机位；便条浮层直接合上 |
| 主视角 | 固定观察方向；玩家不能转动或缩放镜头 |
| `N` | 打开／合上笔记；材料全部在左页，可滚动 |
| 点左页一个词，再点右页空处 | 放置一个临时词条；两词要各点一次左页和右页 |
| 拖左页词到右页 | 同样可以摆词；右页最多三个词 |
| 点右页已放的词，或拖出纸面 | 收回临时词；不会丢掉已知材料 |
| 点右页下方“解释” | 提交当前纸面的全部词，成功后清空临时纸面 |
| 选中静物后，在画布按住左键拖一小笔，或点三笔 | 完成这一件静物的有限落笔；首次点画布只是进入近景 |
| `Esc` | 先合笔记，再退出近景；主视角打开暂停菜单 |

以下所说“组合 A＋B”都指：`N` → 点左页 A → 点右页空处 → 点左页 B → 点右页另一空处 → 点“解释” → 合上笔记。纸面只留指定两词，多余词先点回去。摆放时的淡线不表示配方正确，提交才判断。词条可以重复使用。

游戏提供固定静物构图的有限落笔，不提供自由画画。读便条不会替玩家拿到杯、笔、窗或画中区域；播放动画也不会替玩家取得变化后的观察。

## 共同开场：先画眼前的东西

### 1. 读便条

点桌面前沿、杯子左侧的纸。浮层说明明早交稿，艺术家想不出题目，决定画眼前的杯、笔、灯和夜色。读完右键或 `Esc` 合上。开局是普通黑夜 HDRI，屋顶完整，画布是空白亚麻。

### 2. 画杯子

1. 点桌上的洗笔杯，镜头靠近，得到“杯里的水”和“平静的水面”。
2. 点搭在杯沿的那支画笔，取得“画笔”。这里还没有开始洗笔。
3. 再点杯子，选中要画的杯子。右键返回主视角。
4. 点左边画架上的空白画布进入近景，再拖一笔或点三笔。杯子的色层逐渐落在画布上；桌面不会被当作杯子整条画上去。

### 3. 画笔、灯和窗景

每次都先选现实来源，再返回画布落笔。

| 项目 | 选现实来源 | 接着操作 | 看见什么 |
| --- | --- | --- | --- |
| 笔 | 返回主视角，点杯沿画笔；必要时先点杯子靠近 | 右键返回，点画布进入近景，拖一笔或点三笔 | 画上添出细长笔杆与笔毛 |
| 灯 | 返回主视角，点桌面右侧正在照桌面的主灯 | 点画布，再拖一笔或点三笔 | 添上灯的瓷座和原来静止的灯芯色块 |
| 窗景 | 返回主视角，点真实窗框 | 点画布，再拖一笔或点三笔 | 最后收齐窗、帘与现场构图 |

顺序可以交换，杯子只是建议起点。画齐四件以后稍等最后一层笔触收齐。普通静物落笔是中性的，不占“三次画内解释”的次数。

旁白：“东西都在了。可这水，看着像块玻璃。洗洗笔，换点颜色试试。”

### 4. 实体洗笔，学会“流动”

1. 返回主视角，点洗笔杯靠近。先确认已亲眼记录“平静的水面”。
2. 在杯子近景点杯沿画笔。笔以杯沿为支点入水，笔毛接触液面后才释放蓝色；没有洗笔按钮。
3. 等约 4.2 秒，笔尖离水，再点杯水。取得“散开的水纹”。只洗笔而没有再点水，不会得到这条观察。
4. 组合 **平静的水面＋散开的水纹**，形成“流动”。
5. 返回主视角，点画布进入近景，再点画里杯子的液面，取得“画里的水”。
6. 组合 **流动＋画里的水**。合上笔记，看局部水色和断开的弧形笔触持续变化，周围瓷杯与底色保留。

旁白：“对，就是这样。这才像水。”片刻后提醒看左侧油灯。

### 5. 实体点灯，学会“点亮”

这里用的是桌面左侧尚未点燃的油灯，和右侧一直照着工作区的主灯不同。

1. 右键返回画室，在固定主视角中点左侧油灯进入近景，取得“左边的油灯”和“熄灭的灯芯”。玻璃罩已经放在旁边，不需要把它穿过灯芯移走。
2. 点旁边火柴纸盒，取一根火柴。
3. 点盒侧朝前的砂纸，火柴头沿实体砂纸划过后才亮起。
4. 把鼠标移到裸露灯芯附近，让手持火柴头靠近；等它跟到位置再点灯芯。距离不够只给提示，不隔空点燃。
5. 火柴约 7.5 秒后熄灭。来不及点着就再点砂纸重新划；返回主视角会结束手持。
6. 火苗接上灯芯后等约 1.8 秒，再点油灯，取得“亮起的灯芯”。点火动作不自动奖励这条观察或“点亮”。
7. 组合 **熄灭的灯芯＋亮起的灯芯**，得到“点亮”。
8. 返回，近看画布，再亲点画里灯的灯芯／瓷座区域，取得“画里的灯”。组合 **点亮＋画里的灯**。
9. 看灯芯亮色与瓷座周围的薄暖色逐渐铺开；不让整张画泛白。

旁白：“就添灯芯上这一点。别把整张画都涂白了。”

### 6. 拉开实体帘子，学会“打开”

1. 返回主视角，点真实窗帘，进入窗边近景，取得“窗帘”和“遮住的窗帘”。
2. 点左边从铜导向环垂下来的亚麻拉绳。不要点玻璃或中央分格木。
3. 铜环沿杆向两边走，上缘先收、下摆随后落稳。等约 4.8 秒，再亲点布褶，取得“拉开的窗帘”。拉绳本身不会发这条观察。
4. 组合 **遮住的窗帘＋拉开的窗帘**，得到“打开”。
5. 返回，近看画布，再亲点画里的窗和帘边，取得“画里的窗”。组合 **打开＋画里的窗**。
6. 等约 3.8 秒，画中窗边按实际拉帘后的现场补笔；只让出一小片山坡，窗外房屋没有凭空挪位。

旁白：“对，让出来一点就够了。画里的窗，也照这个样子改。”

到这里，画内水、灯、窗三次解释都完成了，但游戏还没有替玩家定稿。接下来决定继续画，还是把已学画法试到真实物体上。

## 路线 A：把画稿定下来

前提：完成上述画内三次解释，而且从未把画法用于现实杯水、窗框、屋顶或天空。洗笔、点灯和拉帘这些普通实体操作不算偏离。

1. 合上笔记，仍在画布近景时，再点画面空处，看整张画。
2. 观察说明旁出现 **“就交这张”**。点它才确认定稿；只完成第三次画内解释不会自动结束，也不会提前锁住笔记。
3. 画稿留在原画架上晾干，没有凭空飞到门外；旁白说：“好，就这张。别再补了，留着晾干。明早我们拿去交。”
4. 画室、实体帘褶和普通黑夜保留。可以返回主视角看房间，或用 `Esc` 菜单重新开始。世界解释停止，不出现坏结局或嘲笑文案。

当前“交稿”指玩家确认明早交这一张；没有快递、到门外交付或跳到次日的演出。稳定事实 ID 仍沿用 `atelier.canvas_delivered`。

## 路线 B：把画法用于画室

从共同开场分出即可，不要求先做齐三次画内点睛；攻略建议先完成共同开场，亲眼理解三种画法，再探索现实。不要点“就交这张”。已经定稿须从暂停菜单重新开始。发生过一次现实解释后，本局不能突然回到普通定稿收束；仍可给画中添色，但不会再出现定稿入口。

### 1. 试试真实杯水

1. 返回并点真实洗笔杯；“杯里的水”来自这次或此前的实际点击。
2. 组合 **流动＋杯里的水**。合上笔记，看已有颜料在杯沿内持续被搬运，波幅保持在杯口余量内，不生成出杯的水柱。
3. 旁白先等玩家看见变化，再说：“……你在干什么？那不是画布。回到画上来。”若画中水还没完成，末句会提醒先把画里的水画好。

这次实验使路线转向现实。它是推荐的叙事桥梁，不是屋顶的硬性钥匙；也可以先从擦除屋顶开始偏离。

### 2. 擦掉湿色，学会“擦除”

1. 返回主视角，点洗笔杯右边、桌面前沿旧木板上的蓝灰湿色。进入近景，取得“画边的湿色”和“擦前的湿色”。
2. 点木板右边的小块擦笔布。点布只选取擦拭工具，不替代对湿色的调查。
3. 在蓝灰色条左端按住左键，贴着木板向右拖过整条湿色，再松开。短点或只擦一小截不会提交完成；位置不对会提示从左侧开始。
4. 布面前缘受压，后缘带着褶皱跟随，湿颜料在接触后被带走；板和桌不平移、不缩放。松开后等布落稳。
5. 再点露出的木纹，取得“擦后的底色”。完成擦拭不会自动奖励这条观察。
6. 组合 **擦前的湿色＋擦后的底色**，形成“擦除”。

旁白：“木纹露出来了。布上的颜色可别再蹭回去。画边也收拾一下，今天就到这儿。”玩家见过的是湿颜料能被布带走，下一次向建筑应用才显得越界。

### 3. 擦开屋顶中央

1. 返回固定主视角，亲点梁木之间完整的灰蓝屋顶。
2. 亲点中央灰泥，取得“屋顶”。便条、湿色比较和擦拭动画都不能给它。
3. 组合 **擦除＋屋顶**，合上笔记。
4. 约 7.5 秒内，中央大面积的不规则区域逐渐擦开，边缘保留干刷痕；外围完整屋顶和承重梁木仍在。先露出普通黑夜，星夜没有提前出现。
5. 旁白：“……停一下。我让你擦的是木板。屋顶怎么也……别再往上擦了。”
6. 等边缘落稳，再点梁之间实际露出的夜空。取得“天空”。如果点到木梁，视线就被木梁挡住；换到真正的空处点击。

### 4. 让星光亮起来，让笔触流起来

1. 组合 **点亮＋天空**。合上笔记，看夜色里暖星逐渐出现。旁白：“星星已经够亮了。画上还缺什么，你倒是看看画。”
2. 组合 **流动＋天空**。合上笔记，停着看几秒：冷蓝与紫色颜料及笔势持续缓慢演变，星点仍有清楚位置和克制光晕；有限历史交接限制长时间累积拉伸。旁白：“……连天也要动。你先把笔放下，行不行？”
3. 两步可以交换。只做“点亮”还没有流动笔势；只做“流动”还没有暖星。两种解释完成才是完整星夜。
4. 这里沿用 `LivingSkyController` → GPU 颜料平流 → `ApprovedSkyPaint` 的运行时程序化链。`FlowTo` 控制实际颜料与笔势运动，`LightTo` 单独控制暖星。固定主视角由 `FixedViewSky` 生成原 Hero 绘画画幅，并通过真实深度合成到房间后方；两份有限历史平滑交接。没有天空球、星空图片、概念图裁剪或静态 Skybox 替代品。

### 5. 从一道笔迹看见整个房间

1. 完整星夜形成后再等约 5 秒，观察窗边：一道蓝灰干刷笔迹横过后墙灰泥、木框和亚麻帘布；不同材质上，它的位置接得起来。
2. 点窗左侧灰泥上的这道笔迹，鼠标处出现“接连的笔迹”。这次实际调查才取得“接连的笔迹”并记录它跨过几种材料的观察。
3. 旁白：“我看见了。不用把每一处都指给我看。桌子，窗，帘子……这些也都要擦掉？”
4. 返回固定主视角，亲点右侧画室墙面，鼠标处显示“整间画室”。这次点击才取得“房间”。
5. 屋顶显露、完整星夜和笔迹观察都不会自动给“房间”。没有这个单独点击，最终配方不能成功。

### 6. 擦去整间画室

1. 组合 **擦除＋房间**。提交后笔记收起，开始约 16 秒的结尾；这是玩家已经明确提交的解释，不是定时自动进入。
2. 房间使用同一世界坐标笔刷场。笔势从高处经过梁木、墙面、窗框、窗玻璃、帘褶与吊带，再经过桌面、器物和地板；同一表面的颜色、深度和阴影随边沿消失。没有逐个物件平移、缩小或旋转飞散。
3. 局部灯光等笔势经过光源位置后才熄去；不靠一开始把房间压黑来遮掩效果。
4. 窗外实体景物也在同一画面层里被擦去，最后留下完整的运行时流动星夜。
5. 旁白：“等等。……画还在那儿。算了。这次，让我看完。”观察完可以继续查看天空，或按 `Esc` 打开暂停菜单。结尾停止物体调查和笔记解释，没有突然出现的大标题或常驻结算面板。

## 可选实验与失败恢复

| 操作 | 地位与恢复 |
| --- | --- |
| 点亮＋杯里的水 | 可选现实实验。让已有色纹带局部光，不是结尾钥匙；旁白不高兴地提醒杯子不用发光 |
| 擦除＋窗框 | 可选现实实验。仅有漆的木窗构件被擦掉，帘布、灰泥和村落先保留；不要求先做它才能擦屋顶 |
| 重复已有解释 | 不重复刷服从／偏离次数，不重复授予词条 |
| 笔记组合没有成功 | 看中文轻失败说明，收回多余词再试；材料不消耗 |
| 画布不接受落笔 | 确认已亲点画笔，并先在现实选中一件尚未画的静物；首次点画布只是拉近 |
| 洗笔没有结果观察 | 等笔尖离水，再亲点水；动画不会自动观察 |
| 点火失败 | 重新划亮火柴，把火柴头真正送到灯芯附近后再点 |
| 帘子动了却没有“打开” | 等布褶落稳，再点帘布，比较前后两条观察 |
| 擦布没有完成 | 已近看湿色并点过布，从湿色左边按住，拖到右边；不要只点一下 |
| 天空点不到 | 等屋顶擦开完成，在梁间真正显露处点击；不要点还在的梁或灰泥边缘 |
| 没有“房间” | 完整星夜后亲点窗左侧连续笔迹，再亲点右侧墙面 |
| 定稿后想试另一条路线 | `Esc` → “重新开始”；重开取消旧演出并清空临时选择与一次性反馈 |

领域中尚留有“纸上的湿色／纸面流动”候选规则，本场景没有接入对应实体输入，攻略不把它写成可玩的步骤。自由绘画、独立美术重绘的静物画、手部握持、接触 Foley 与角色配音也不在本轮完成范围。

## 验收边界

具体本机包、截图、Console 和规则测试结果见本轮[画室玩法实施记录](画室玩法实施记录.md)。显式命令和 UI 事件回放可以证明状态链、拾取适配及实际渲染，不能写成真人鼠标试玩或首次理解度通过。真人试玩仍需分别验证操作直觉、提示节奏与每一次现实解释的主观理解。
