### 实际操作与画面

1. 玩家亲点左侧油灯取得熄灭灯芯；原扫描玻璃罩预先放在旁边，灯座保持原位。
2. 亲点火柴纸盒取一根，再点砂纸划过。火柴头沿真实砂纸接触面运动，随后才燃起；燃烧有时间限制，可重新划亮。
3. 鼠标把火柴头送到裸露灯芯附近并点击，接触距离满足后提交点灯。灯芯事实立即成立，火苗根部固定，连续曲面上端由 Shader 热流扰动，局部光逐渐稳定。没有延迟发事实。
4. 点着灯没有自动得到“点亮”。火苗稳定后玩家再亲点油灯取得亮起观察，比较前后并提交。亲点画中的灯后，才能给画中灯芯添色；暖色短笔触保留瓷座和周围画面。

点灯工作簇、检视机位、网格、材质与碰撞拾取全部通过 `AtelierLampRevision` 的 Unity Editor API 增量创建。复用 Poly Haven CC0 扫描油灯；原创火柴盒有厚纸套、空心抽屉、木杆、连续药头与砂纸压痕。本阶段新增 30 个网格文件（609,220 bytes）和 9 个材质（29,262 bytes），没有新下载。旧纸纤维／印刷磨损与三维热流 Shader 为项目原创，调用 URP 官方库；中文仍为 Noto OFL。详见[来源与许可](../../Assets/_Game/Content/ArtRebuild/Gameplay/来源与许可.md)。暂存候选未新增导入或采用。

### 实现与玩家看到的因果

- **主动定稿**：三次画内点睛只形成可定稿状态；玩家仍可继续探索。只有近看画布，再点“就交这张”才确认。画留在画架上晾干，旁白说次日拿去交；没有把静止画稿说成已经送出，也不让画稿飞走。
- **接触擦湿色**：杯边新增旧木板、贴面的蓝灰湿色和柔软擦笔布。玩家亲点湿色，选布，从左向右实际拖擦；接触压力带动布面前缘和后缘褶皱，松手停在当前位置。短擦保留局部结果，不把颜料重新长回去；再次起笔即使命中留下的布面，也可以继续擦，不会被工具自己的拾取框挡住。完成后再亲点木纹，才可比较学到“擦除”。
- **屋顶显露**：亲点中央屋顶、提交“擦除＋屋顶”后，约 7.5 秒擦开大面积不规则区域；外围厚实屋顶和梁木留下。先露出普通黑夜，之后必须亲点真正露出的天空。
- **后期星夜**：点亮与流动由两个独立解释驱动，可以换序。复用 `LivingSkyController` 和 `ApprovedSkyPaint` 的 GPU 颜料数据；玩法专用全方向 Shader 保留认可正面构图，补齐侧后方。实际对照截图可见同机位笔触持续运动；没有星图、概念图裁剪或静态贴图代替程序生成。
- **整体调查**：完整星夜后，连续干刷笔迹经过灰泥、木框和亚麻；亲点笔迹形成观察，再另点右侧墙面看整间画室，才得到“房间”。任何演出、便条、概念或延时都没有替玩家授予它。
- **全房间擦除**：明确提交“擦除＋房间”后约 16 秒，同一世界笔刷场经过梁、墙、窗框、玻璃、帘褶、吊带、器物、画架、地板和窗外实体景物；颜色、深度、阴影一起裁剪。边沿使用连续干刷纤维和克制的提色，未给物件做飞散、平移或缩放。灯光等笔势到达光源后才熄去，最终只有流动星夜；结尾回到预设画面，也可暂停和重开，不再调查或解释。

新增工作簇和绑定通过 `AtelierFinaleRevision.Apply()` 的 Unity Editor API 增量安装。新增 3 个原创网格（228,231 bytes）、1 个材质、8 个 Shader 与 6 个 HLSL；木纹与亚麻复用已验收 CC0 素材，原材质只在运行时克隆，销毁时恢复并释放。素材、许可和未采用候选见[本轮来源表](../../Assets/_Game/Content/ArtRebuild/Gameplay/来源与许可.md)。没有新下载、没有导入暂存包、新增游戏纹理为 0。
