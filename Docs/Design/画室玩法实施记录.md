### 实际操作与画面

1. 玩家亲点左侧油灯取得熄灭灯芯；原扫描玻璃罩预先放在旁边，灯座保持原位。
2. 亲点火柴纸盒取一根，再点砂纸划过。火柴头沿真实砂纸接触面运动，随后才燃起；燃烧有时间限制，可重新划亮。
3. 鼠标把火柴头送到裸露灯芯附近并点击，接触距离满足后提交点灯。灯芯事实立即成立，火苗根部固定，连续曲面上端由 Shader 热流扰动，局部光逐渐稳定。没有延迟发事实。
4. 点着灯没有自动得到“点亮”。火苗稳定后玩家再亲点油灯取得亮起观察，比较前后并提交。亲点画中的灯后，才能给画中灯芯添色；暖色短笔触保留瓷座和周围画面。

点灯工作簇、检视机位、网格、材质与碰撞拾取全部通过 `AtelierLampRevision` 的 Unity Editor API 增量创建。复用 Poly Haven CC0 扫描油灯；原创火柴盒有厚纸套、空心抽屉、木杆、连续药头与砂纸压痕。本阶段新增 30 个网格文件（609,220 bytes）和 9 个材质（29,262 bytes），没有新下载。旧纸纤维／印刷磨损与三维热流 Shader 为项目原创，调用 URP 官方库；中文仍为 Noto OFL。详见[来源与许可](../../Assets/_Game/Content/ArtRebuild/Gameplay/来源与许可.md)。暂存候选未新增导入或采用。

实际看到了局部暖光落在瓷座、旧桌面和旁边花瓶上，窗边冷色仍保留。首轮灯颈过曝，已降低光源；初次火苗网格因浮点 `sin(pi)` 的微小负值产生 NaN，已钳制后重建。历史失败报告保留在 Logs；最终网格顶点与 Shader 检查无错误。没有用整体 Bloom／雾掩盖此问题。
