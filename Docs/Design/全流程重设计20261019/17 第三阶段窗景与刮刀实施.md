# 第三阶段窗景与刮刀实施

2026年10月20日。接续16号修订，在`codex/atelier-scene-flow`的AtelierPlayable实现P13至P17。台词沿用09号文档O09、O10、O11、O12、O14及N05；新增文字只说明操作和当前门槛。

## 玩家操作

1. 第二层完成后等待N04完整播完。窗框、窗外景物、桌上干颜料板和右侧调色刮刀随后渐显；此前物件保持实色，书柜、灯区和屋顶继续草稿。显色完成才交回输入。
2. 点窗景进入固定近景，分别点近处屋檐和远处亮灯的小屋。两个热点分别记现实、夜色；只有玩家再点“离远看看”，比较后才得到星辰。这里指地面窗灯的意象，未在夜空增加实际星点。观察顺序不限。
3. 点干颜料板，再点“细看颜料”，得到混乱和原稿O11。可点“试着取色”看笔尖留下浅痕，颜料不变湿，也不完成工具教学。单纯进入板面不发灰词、不代领刮刀。
4. 亲点板右侧的调色刮刀，默认刀刃。在左半干壳区域拖一小段，露出木底；切“刀面推色”，在右半软色区域拖动，看到薄色带。各自达到试区横向40%后，当次记录经验。也可以在对应试区短点三次，分段完成同一路径。
5. 在笔记合成混乱＋夜色→肉身、现实＋星辰→当下，再以肉身＋当下→夜城笔刷。每次最多两词，指定灰词成功才消耗，右页同帧出现蓝色结果。四个新灰词都有配方用途；凝固、空白、洁净仅保留为可见状态与介绍，不再生成额外灰词。
6. 点画布，用原始`3.png`绘制第三层，前两层保留。至少三笔可收层，默认五笔用尽100单位颜料。笔刷可以先形成、先画；若没试过刀刃或刀面，“完成绘画”保持禁用并显示原因，“去颜料板试刀”可直接返回工具近景。该定位不授予未亲点的来源。
7. 三笔与两种工具经验均成立后，亲点“完成绘画”，播放原稿N05。当前本批止于第三层和N05交接；第四阶段点灯、暖星及两个结尾仍待下一批。没有用字幕或一个假按钮冒充第四阶段完成。

## 规则和输入边界

窗、干颜料板、刮刀均要求`Finished(2)`，旧`atelier.trial`湿色板的身份保留。新板为`atelier.flow.dry_palette`，刮刀为`atelier.flow.palette_knife`；窗沿用`studio.window`。近远观察、比较、细看、刮开和推色均通过同一会话的有限SceneAction进入领域规则，物件与概念不由视觉组件授予。

板面接触必须命中实际SurfacePicking的首个射线面，UV与Shader使用同一世界XZ范围。刀刃只作用左区，刀面只作用右区；板外、错误区域、未拿工具、未细看、笔记打开、暂停和镜头移动时不提交。返回、失焦、切模式与打开笔记取消尚未结束的手势。已经留下的局部刀痕和覆盖保留，相同位置重复拖动不累计横向覆盖。松开后才算一次辅助短点，按住不刷次数。

完成经验以GameState事实为准；接触路径为有上限的本次表面表现。每面最多64段，达到上限后复用最后一段，避免无限数组。新会话清空本次刀痕；有完成事实时可恢复典型结果。刀刃推广TA04的干壳裂纹和露木，刀面推广其蓝色软颜料薄带，刀具朝向和预览也沿用已验收方向。未新增手部、角色配音或接触Foley。

## 装配与显色

独立`PF_干颜料板`与`PF_调色刮刀`只包含视觉；Logic、固定近景与阶段控制位于主场景的“四阶段第三阶段_Logic与近景”。板和工具放在主桌右侧，主画幅能直接命中；为留出空间，仅把无交互的装饰笔筒与筒内三支笔移至桌面右后方，实体洗笔杯、洗笔画笔、便签、石膏像、干笔和碎镜保留原位置。

第三阶段显色清单只追加窗框、板和刀。连续村落使用一个最靠近房间边界为Z=6米的独立显色体积，避免数百个村落Renderer挤满32组槽位；它不包含室内或屋顶。板旁有一小块按桌高限定的接触显色，跟随N04后的渐显。镜内复制同样体积许可。普通阶段推进不会调用RevealRoof。

安装菜单：`游戏/新四阶段流程/接入第三阶段窗景与刮刀`，实现为`AtelierFlowStageThreeBuilder.Install()`。安装拒绝Play和未保存场景，只保存开发副本。正式AtelierNight、LightingData、Build Settings及已有QualitySettings修改保留。

## UI同学接入

正式笔记、笔刷页、导读和Workspace继续由UI分支维护。第三阶段的世界接触和当前功能占位由场景侧维护，后续可以替换控件外观，复用以下接口，不另建工具经验或颜料状态。

| 入口 | 用法 |
| --- | --- |
| `CanvasPort.CanFinish / FinishBlockedReason` | 直接读取领域的完整收层许可，不能只判断Count>=3；第三层还检查两面经验 |
| `StageThree.ObserveWindowDetail(bool far)` | 对应真实近远热点，必须在窗景近景且交互开放 |
| `StageThree.CompareWindow()` | 比较按钮，必须亲看过两处；当前占位会切预设后退镜头 |
| `StageThree.StudyPalette()` | 细看板面，不自动拿工具 |
| `StageThree.Palette.TryBrush()` | 只显示干壳浅痕和功能提示，不发材料 |
| `Palette.Equipped / FaceMode / SelectMode(bool)` | 读取已选工具和模式，切模式取消旧手势 |
| `Palette.Contact(from,to,face,assistTap)` | 有效板面UV与已结束短点输入，调用后从同一会话读事实；不传完成值 |
| `Palette.DryCoverage / WetCoverage / CancelGesture()` | 只读接触进度与明确取消，不替代GameState完成事实 |
| `Flow.OpenPaletteForPractice()` | 完成门槛旁的来源定位，只移镜头，不代领板或工具 |

工具功能占位单独保存为`PF_第三阶段功能占位`，主场景只装配实例和外部引用，不修改Notebook母版或正式Workspace。UI联调继续合并场景分支最新提交，保留UI分支工作，不强制重置。

## 开发快进

刀刃和刀面按接触所在的左右区域跟随切换，不再要求先在起手处切模式；干湿覆盖阈值从16/40降到12/40，短拖动也能积累。最终屋顶/房间的接触长度阈值也同步放宽，匹配真实鼠标的短推拉。板旁与接触中的刮刀视觉放大到1.5倍；第一次拿起时播放“文森特拿起了刮刀，他想干什么？”并提示可以轻点三下或按住滑动使用刮刀。

菜单`游戏/新四阶段流程/快进到第三阶段`（`Assets/_Game/Editor/ArtRebuild/AtelierStageThreeQuickStart.cs`）用于测试第三阶段：若当前不在Play，会打开`AtelierPlayable`并进入Play；会话`Start`后调用`AtelierFlowGameplay.FastForwardToThirdStage()`。

快进状态：前两层按正常画布命令完成3/5笔并产生`Finished(1/2)`；补前两阶段23个来源、观察、概念和前两枚笔刷，以及`IntroRead/Washed/MirrorCompared`；跳过N03/N04和开场黑场；灯、屋顶、第四阶段均未推进；第三阶段窗景、干壳板、刮刀可见；相机回主视角，笔记关闭，第三阶段的窗灯和干湿观察仍需玩家自己做。菜单只走显式调试入口，不影响正常开局。
