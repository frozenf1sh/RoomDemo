## 预览使用

独立打开预览场景后进入Play，使用“上一状态”“下一状态”或Inspector切换FakePaintingPreview.Case；“查看笔刷结果”打开最小形成页。

固定快照覆盖：零笔、两笔、三笔可收层、最后一笔固定大小、耗尽、第三阶段刀面缺项、无笔刷、请求拒绝、长中文、开场输入锁和提交中。

Fake只观察操作意图，不执行第二套预算，不实例化RuleEngine。预览中的半透明图样用于手势示意；真实预览调用CanvasPort同一套面积标定和合法性检查。Fake代码仅在UNITY_EDITOR编译，不装入正式玩家场景。不要把固定快照的通知当作真实扣量证据。

## 正式场景接线

通过“接入AtelierPlayable第一批UI”可重复执行地创建`第一批UI组合根`；已有根不会重复创建。该入口仅保存`AtelierPlayable.unity`中的组合根和引用，以下为其装配清单。

| 组件 | 注入内容 | 生命周期与行为 |
| --- | --- | --- |
| AtelierCanvasWorkspace | 母版内AtelierCanvasWorkspaceReferences | 只维护当前角度、成本选择和未提交手势 |
| AtelierPaintingSessionAdapter | Gameplay=场景现有AtelierFlowGameplay；Workspace=新母版组件 | 等Session完成Start绑定后接管旧控件；禁用时解绑并恢复占位输入 |
| AtelierBrushResultAdapter | Gameplay=同一控制器；View=笔刷结果母版 | 订阅真实CombinationSucceeded；只展示KnownClues中已有的稳定笔刷ID |
| AtelierBrushResultView | 母版自带Panel/Title/Sources/Preview/Aspect/Back/Close | 返回组合不改选择；收起笔记仅请求关闭书，不自动进入画架 |
| Canvas | 项目中文字体；1920×1080参考；Match=0.5 | UI母版自行控制内部排版，主场景实例覆盖由装配侧清理 |

AtelierPaintingSessionAdapter应放在持续启用的组合根，而不是按近景开关的Panel上。Workspace通过CanvasGroup隐藏和禁用，保留端口生命周期。无需Find外部对象。

真实适配器通过最近世界射线命中Painting逻辑Collider取得textureCoord；被其他碰撞体遮挡时拒绝映射。预览RectTransform只在Fake中使用。后续场景侧若提供专门映射入口，应替换TryMap实现，UI手势合同不变。

当前世界画布直接显示真实RT。References.Artwork仍绑定同一CanvasTexture，ShowArtworkInUI默认关闭，避免在世界射线上叠一张位置不符的作品；需要独立作品查看器时才开启，并由装配侧设置对应画幅。

## 字段与命令

AtelierPaintingSnapshot复制会话世代、作品版本、当前层、笔刷ID、两类纹理、剩余量、笔数、合法成本范围、推荐参数、完成/撤销/返回许可、工具状态和提交状态。UI不能回写这些值。

每次按下生成AtelierStrokeIntent，锁定世代、版本、笔触ID、成本与角度；松开只补入最终UV。真实命令使用锁定的世代与版本；旧版本、重复身份或非法落点交由已有应用层检查。UI不会预扣颜料、释放RT或自动封层。

滑块本地选择不进入GameState；世界预览与正式提交采用同一参数。已捕获手势遇到UI、画布外、N/Tab/Esc/右键、版本变化、失焦或禁用时终止。提交拒绝显示明确中文原因，下一帧可重新预览。

当前第一批真实接口尚未实现刀面动作，因此真实CanUseKnife保持关闭，RequestToolMode明确拒绝。三四层的收层缺项按现有领域规则显示；正式后续工具许可由场景侧补齐合同后接入。

## 构建验证入口

游戏 → 四阶段UI → 构建第一批真实会话验证。

构建器通过Editor API生成临时主场景副本，只在副本装配新UI，显式构建Windows Player到Builds/AtelierUIFirstBatch/AtelierUIFirstBatch.exe。完成或失败后关闭并删除临时副本，恢复构建可能写回的QualitySettings与ProjectSettings原始内容。验证期间临时创建的Resources目录会在无需保留时移除。正式Build Settings和AtelierPlayable不保存修改。

验证Player无参数运行可人工操作。传入 --atelier-ui-review-output 和输出目录后运行真实会话自动回放；可加 --ui-early-finish 验证三笔提前结束，否则走六笔耗尽。自动回放通过真实调查、洗笔、配方、UI按钮和命令端口执行，不调试授予。字体许可证随验证包分发。

自动回放检查：形成页原图、关闭笔记不自动入画架、外部Workspace接管、零/两/三笔按钮、实际UV映射、旧版本拒绝、撤销、返回重进保留、末笔范围、六笔耗尽和主动收层。自动命令与截图不代表真人鼠标或首次理解度验收。
