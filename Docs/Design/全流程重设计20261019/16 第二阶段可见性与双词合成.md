# 第二阶段可见性与双词合成

2026年10月20日，按冻鱼本轮反馈修订。第二阶段原本已有干画笔、碎镜片和配方，但摆放未覆盖到玩家的固定画幅，实际体验不能按“已接入”判定完成。本轮先修复这一处流程断点，并实现新的双词合成要求。

## 玩家接下来怎么继续

第一层至少画三笔，主动点“完成绘画”，完整N03结束后第二阶段物件才显色。石膏像、完整手镜之外，还有石膏像前空桌面上的黑色干画笔，以及画面左下安全范围内纸套中的四块已有碎镜。都需亲自点击，不自动收集，也不要求打碎手镜。

1. 看石膏像，得到固定；看手镜并主动转动，得到翻转。
2. 在笔记用固定＋翻转合成扭曲。
3. 看黑色干画笔，得到黑色；看纸套中的碎镜片，得到锋利。
4. 用黑色＋锋利合成粗犷，再用扭曲＋粗犷合成柏影笔刷。
5. 返回画室、点画布，在保留卷涡的作品上绘制柏影。默认五笔用尽颜料，三笔起允许主动收层。
6. 点“完成绘画”，进入N04交接。

本轮可玩范围仍止于第二层及N04交接。完整四阶段尚未完成；下一批按P13至P17接窗景的近远调查、干颜料板、刀刃揭底／刀面推色、夜城笔刷和第三层完成门槛，再接点灯与两种结尾。不能把N04字幕出现写成第三阶段已可玩。

检查反馈时玩家已经处于第二阶段。主镜头归一化投影中，干笔中心为`(0.020,-0.006)`，碎镜中心为`(0.419,-0.020)`，两者都低于画幅下边。此前只检查了射线能命中，没有检查投影是否在屏幕内。

## 双词合成的当前规则

- 当前四阶段组合区最多两张活动卡，点放和拖入都拒绝第三张，不挤掉原来的两张。领域命令也拒绝三个输入；绘画的每层笔数不因此改成两笔。
- 成功时两张旧输入卡在同一次回调里立即隐藏并移除，蓝色结果卡完整出现，取消旧的打字及延迟清空。不会在稍后把玩家已经放入的下一组词误删。
- 本次指定消费的灰色观察从左页可用材料中移除；重复观察原物不重新发一份。失败保留原两张卡，不消费任何材料。
- 物体来源与发现历史保留。已经形成的蓝色概念可重用；合成笔刷时移除其右页临时卡，但不消费左页蓝色概念。新会话清空上局消费记录。
- 蓝色结果是可操作的右页卡，占一格。可以再放一个概念继续合成；要另组两张灰词时，先点击或拖回当前结果，它仍留在左页可用列表。

当前消费表：透明＋蓝色→冰蓝、流动＋奔放→卷涡、固定＋翻转→扭曲、黑色＋锋利→粗犷。这里“蓝色”这一颜料观察本身是灰色材料卡，“冰蓝”等形成结果才是蓝色概念卡。没有把所有灰词、无关词或物体一起清掉。

## UI同学需要同步的真实协议

本轮为当前可玩版修复`NotebookView`与`NotebookCanvasView`，没有开发正式Workspace、笔记导读或笔刷详情页。UI同学继续原分支并行，联调时合并场景分支最新提交，保留自己的排版和Prefab。

| 入口 | 当前行为 |
| --- | --- |
| `Rules.MaximumCombinationInputs` | 当前内容为2；历史三元关卡仅保持兼容 |
| `State.KnownClues` / `Knows` | 仍是发现历史，不能据此重建可拖动材料栏 |
| `State.AvailableClues` / `CanUseClue` | 当前可用材料；左页、拖入和点放都用这一查询 |
| `State.ConsumedClues` | 已用材料的只读历史，重开随新会话清空 |
| `SemanticRecipe.ConsumedInputs` | 内容显式声明成功才消费哪些输入；引擎不为具体词写特例 |
| `CombinationSucceeded.ConsumedClues` / `ProducedClues` | 同一条成功结果携带消费与产出；发布时领域整条命令已经完成 |
| `NotebookCanvasView.ShowResult` | 同帧撤去旧卡并放入领域实际产出；不匹配配方、不写材料账本 |

正式UI成功处理顺序：停用旧输入卡与其拾取 → 清临时选择／旧清理计时器 → 按真实状态刷新可用材料 → 放入蓝色结果 → 刷新提交许可。不要等待结果动画结束才消费材料，也不要只在UI删除而仍让领域重复使用。来源回看仍读取已知历史。

## 本轮追加：精简灰词与动作结果

当前前两阶段只保留八个真正参与配方的灰词：透明、蓝色、流动、奔放、固定、翻转、黑色、锋利。映射、杂乱、苍白、规整、虚幻、干涸、脆弱、错乱不再生成词条；原稿介绍中的形容和台词保留，不为删词改写角色语气。

点击洗笔杯与完整手镜只记录各自物体并显示说明，不给任何灰词。笔尖实际入水并提交有效洗笔时才给透明、蓝色、流动；镜面主动转到有效比较角度时才给翻转。仅拿起、靠近、等待或看一段动画不代替动作。黑笔摆放还要验证整个投影、真实桌面支撑和源目标拾取，不能只测屏幕投影。
