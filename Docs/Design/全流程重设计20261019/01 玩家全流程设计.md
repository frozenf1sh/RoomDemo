# 画室四阶段玩家全流程设计

日期：2026年10月19日；开场与UI分工按2026年10月20日用户反馈修订。对象：策划、关卡、程序、UI、TA、音频与试玩主持人。

本方案按原稿的调查、合成、绘画和双结局组织流程。每一次继续游戏的理由，都来自刚才亲手做过的操作及看见的结果。四阶段分别生成卷涡、柏影、夜城、暖星四类有限笔刷，累积在同一张画上；最后由玩家选择留下作品，或把刮开颜料的动作迁移到屋面，再亲手擦开画室。

这是完整流程设计，实际完成范围以[14 第二阶段实施](<14 第二阶段实现与逐物件显色.md>)为准；三、四阶段尚待接入。以下时间、工具接触阈值与提示参数是首轮调参起点，均需真人试玩验证。

## 一 设计依据与明确调整

主要依据为《全流程 (1).docx》及《新流程体验反馈与待设计问题.md》。旧版可玩场景只作为可复用能力来源，不决定新玩法必须保留哪些动作。

| 常规结局自动回第三阶段 | 正常结束后提供重新开始和从最终落笔前再试；后者明确是本轮回看 | 正常完成具有完整收束，不伪装成失败或强迫重做 |

## 二 全局操作和玩家契约

**2026年10月19日策划补充已采纳。** 每阶段颜料有总量，默认五至六笔用尽；不能零笔跳过；至少三笔可以提前结束。自由放置与有限颜料并存。原稿之外早期设想的覆盖率、分区和两笔通过门槛已全部取消，不构成当前方案。

主镜头固定，鼠标拖动和滚轮不转头、不缩放。点击实体进入预设近景，右键或右上角“返回画室”返回；Esc依次关闭当前浮层、退出近景、打开暂停。屋面异常位于现有主画面上方可见范围内，不能要求玩家用未提供的抬头操作发现它。必要时使用玩家点击后触发的屋面近景。

悬停仅表示可调查，不自动收集。首次点击实体才记录该物体；可见性质由这次实际调查或亲手操作产生。书、便条、旁白不代发其他实物。做完洗笔、刮色、点灯后，不再要求额外点击同一物体领取结果。动作必须有接触证据，结果立即开始出现，首次结果和新灵感各提示一次。

N01完整播完后N可开合笔记；开场期间所有游戏交互及笔记入口关闭，不提供空格/Esc跳过。之后短暂镜头切换、接触提交与结束演出仍按输入优先级阻挡。笔记左页可用材料一列排列；右页最多两项，第三项拒绝放入，摆放淡线不预判成功。点“合成”才提交有限配方。成功时用过的灰色观察退出可用材料，历史保留；蓝色概念可重用。两张输入卡同帧清空并替换为蓝色结果卡，不等待打字或淡出。错误尝试保留选项，文案说明当前缺的是联系，不惩罚、不扣物品。

新灵感提示采用功能性文字“已获得新灵感”，小型笔记提醒闪至打开；不会在画面常驻任务大面板。灵感只指出可讨论的关系，不替玩家合成。画布没有审美分数，所有有效笔触都能保留。阶段锁定的是下一种笔刷，不抹去前面的作品与已知材料。

10月20日修订扩大第一阶段遮挡：只保留杯水、洗笔画笔、便签、画布和窗台涂鸦的实色，右侧灯、布料、散落颜料、书柜、天花板与其余外围转为底稿。每一阶段先完整播放对应过场旁白，再用约1.4秒只显色本阶段已实现交互的物件。第一层后只新增石膏、手镜、干笔和已有碎片，背景保持底稿；第三阶段只新增窗景、干颜料板和刮刀，第四阶段只新增点灯所需物件。屋顶独立保留遮挡，直到第四阶段允许试刮、且相关旁白已播完才显色。清晰范围跟随世界表面，不是把物品从场景删除。后续物件在规则许可和视觉显色上同步接入。

## 四 开场 从催稿到重新看见

### P00 黑场与失焦中的开场旁白

**我看到与听到。** 进场时世界从黑色开始，UI左上自动显示缪斯原稿N01。房间已经处于第一阶段底稿遮挡，黑色约2.4秒退去，失焦约4.8秒退去；没有先完整看清房间、读了便签又突然被遮住的反复。

**我能做。** N01整组播完前不接受世界点击、笔记N/Tab、返回、暂停或空格跳过，也不显示笔记入口和获取提示。OS窗口关闭不属于玩法输入。完整台词播放完后，当前物件逐渐显色，渐显完成才交回操作，不用固定四秒计时器猜测旁白结束；黑场和模糊提前消失后仍是全底稿轮廓，不提前显示物件实色。

**合理性和衔接。** 这是用户明确选择的被动开场。字幕保持完整句和稳定位置，不要求玩家在失焦中找按钮，不借播放完成授予任何物体或伪造已读便签。实际等待时长由原稿字幕节奏决定，后续配音接入以同一播放完成信号联调。

### P01 清晰目标与可选便签

**我看到。** 杯水、洗笔画笔、空画布、桌沿便签和窗台涂鸦保持实色，外围以炭稿保留轮廓。桌子右边的灯、布料与颜料、书柜和天花板也遮挡。N01结束、物件渐显完成后出现小型“笔记 · N”入口，才开始允许悬停和点击。

**我做。** 可以先点杯、画笔或涂鸦，也可以读便签。便签采用用户要求的新第一人称文字：“快交稿了，我还是一点灵感都没有。先在房间里找找想法吧。窗台上还放着我小时候的那幅涂鸦。”按完整段落展示，不以强制断句制造情绪。关闭便签不重播开场、不重置遮挡。

**我收到。** 每次亲点只记录该来源和可见性质。便签只解释动机，没有免费杯、画笔、概念或笔刷。新词条在笔记入口上方轻提示；第一次主动开书可查看位置介绍，这两项正式UI由UI同学实现。

**合理性和衔接。** 旁白已邀请观察熟悉物件，开放后可以直接照做；便签补充交稿和涂鸦线索，不再成为另一个隐藏前置。下一步由我看见的杯水和蓝色画笔引出洗笔。

## 五 阶段一 从观察得到第一笔

### P02 亲点水杯 看见透明

**我看到。** 杯中水能透出浅色杯底或浸水笔杆，局部有清晰折射；不要求杯子本身透明。主视角有小范围杯沿亮面；点击后近景能看清水与杯底的关系。

**我做。** 点杯。首次调查只记录杯这一物体并显示说明，不提前给灰色词条；笔尖实际入水完成有效洗笔后，再同次记录“透明、蓝色、流动”。同一近景显示搭在杯沿、带蓝色笔毛的画笔。

**合理性。** 抽象性质来自可见证据，不奖励看不出的“冰冷”。杯与笔相邻，下一动作有物理目标；先点笔也会把镜头带到同一工作区，但不会代授杯物体，须亲点杯。

### P03 亲手洗笔 当场获得散色观察

**我做。** 在杯近景点蓝笔，再点水面，或将笔尖拖入水面；两种输入同结果。第一次仅给功能提示“把笔尖放进水里”，不出现洗笔大按钮。

**我看到。** 笔尖先接触水面，接触点立即吐出蓝色小团，约1.5秒分成可见颜料丝，在杯口内形成明显的弯曲流带。水声与接触同帧开始。玩家可以返回；返回时提交过的结果保留，不要求等待整段摇笔。

**我收到。** 接触并释放首团颜料的有效输入提交“洗笔”动作。应用层与规则即时记录透明、蓝色、流动观察；反馈在首团可见时显示“蓝色在水里散开了”。流动作为观察，不直接授“卷涡”概念。从画笔先进入近景时，先亲点水面完成杯的调查，再接受洗笔接触；这一真实点击即可，不必返回主画面重新点杯。点击杯和拿起笔都不提前给灰词，洗笔结果不再需要调查一次才能收录。

**合理性和衔接。** 直接解决“洗完还要再点水领奖”。动作提交点与可见结果一致，演出导演不在几秒后偷偷奖励事实。重复洗笔只重播轻效果，不刷条目或提示。

### P04 亲点蜡笔画 理解奔放

**我看到。** 蜡笔画放在策划阶段图所示窗台右下方的小画位置，正面朝主镜头；点击后近景再读画面；封面和正面不混用。点击进入近景，能见线条跨出轮廓、几条连续弧线，没有“童年画得差”的评价。

**我收到。** 记录蜡笔画与奔放。内心话沿用原稿蜡笔画介绍词O03，不再新增比喻。杂乱、鲜艳保留为画面描述，不生成无配方用途的灰词。

**合理性和衔接。** 蓝色来自当前操作，奔放来自可见画痕。关键证据齐备时使用原稿提示“现在来准备画画吧，打开笔记本看看”。不要求检查桌灯等可选意义物。

### P05 在笔记中亲手联系

**我做。** 按N。左页保持透明、蓝色、流动、奔放的来源小缩略图，右页留空。第一次只出现一条可关闭说明：“把两项材料放到右页，再试着联系。”选透明与蓝色，提交获得冰蓝；选流动与奔放，提交获得卷涡。两条先后不限。

**我看懂。** 每次成功先显示关联说明和一小块色样或线样，再把成品加入同一材料列。冰蓝、卷涡齐备后，显示原稿N02；右页提示这两项可继续形成阶段笔刷。玩家再提交两者，得到卷涡笔刷。

**合理性。** 不靠猜词：证据详情里的光穿水、散色弧线和越界画痕分别支持配方。成功前不连绿线；失败沿用原稿“似乎没什么联系”，不宣称世界中绝不相关。连续两次未成可点“看看相关记录”，展开来源描述；再点才显示明确材料建议。无时间自动解谜。

### P06 笔刷成为可操作的东西

**我收到。** 右页出现原始1.png笔刷图样，并使用原稿成功提示。沿用原稿关掉笔记本，再亲点画布；画架可给一次既有金丝提示，不自动移镜头。

**合理性。** 玩家知道得到的是本阶段画法，而不是必须再找一支实物画笔。图样缩略图只在UI预览，不作为星空贴图。

### P07 在画布上试出第一层

**我看到。** 画布为稳定的暗蓝底层。光标在画布内显示半透明笔印预览，不改变画面；点按放下一枚笔刷图样，按住拖动只调整这枚预览的位置，松开才落下一笔，不沿长路径无限盖章。画布内可自由放置、旋转、叠放，不限定天空分区。画布外不落笔。大小与角度控件只在近景出现，默认值可直接使用。

**我做。** 自由放置卷涡笔印，每笔大小消耗对应颜料。点按与拖动后松开均只算一笔。每层默认准备五或六笔的总颜料；至少亲自落三笔后可提前结束。撤销当前层最后一笔，同时退还其原始颜料、恢复落笔次数与当时的可用大小范围，不擦掉旧层。没有强制临摹和分数。

**门槛。** 当前层0至2笔不能完成，明确显示“再落X笔后可完成”。达到3笔即允许点“完成绘画”，旁边提示“还有颜料，可以继续”；提前结束放弃本层余量，不带往下一层。默认阶段一、四各6笔，阶段二、三各5笔用尽预算；用尽后停止落笔并显示“颜料用完了，这一层可以收笔了”，仍由玩家点击推进。没有覆盖率、位置分区、笔触间距或审美门槛。

**我提交。** 点“完成绘画”。按钮只推进阶段，不定稿。已画内容保留，当前笔刷归入记录；缪斯先完整播放原稿阶段二台词组N03，再让石膏像、手镜、干画笔与已有碎片约1.4秒渐显；背景和屋顶继续底稿。

**合理性和衔接。** 三笔是策划明确的最低参与量；有限颜料约束本阶段创作篇幅，位置由玩家决定。每笔提交前预先约束大小，使剩余预算仍可由剩余五或六笔计划中的落笔消耗，并确保最后一笔不低于最小、也不高于最大。具体算法见《04 UI开发交接与画布工作》；不能在松开后偷偷改变预览大小。

## 六 阶段二 从规整走向有棱角的形

### P08 新区域显色 目标仍在固定画幅内

**我看到。** N03整组旁白结束后，策划阶段图中画架前左侧台面的石膏像、前桌左侧手镜及已有碎镜片和干笔从炭稿恢复材质；杯和蜡笔画保持可见。石膏像不放到主镜头拍不到的背后。所有必要目标在主画面至少有清楚可辨的轮廓，细节点击后再看。

**合理性。** 视觉开放与输入开放同一阶段发生，不能“看见了点不到”。点击未开放对象只给中性“还看不清这里”，不当作错误操作。

### P09 亲点石膏像 先理解固定

**我做。** 点像，近景显示稳定正面和规整肩线，取得固定。介绍词使用原稿O04，意义物提示使用原稿O05；苍白、规整保留在描述中，不再占用材料列表。

**衔接。** 近景保留手镜与石膏像的空间关系，通过摆放提供比较对象，不新增角色台词。不会自动调查手镜。

### P10 转手镜 亲眼比较翻转

**我做。** 亲点手镜拿起，介绍词使用原稿O07；在固定近景水平拖动，或点左右转向按钮。角度限制为直视左右各15度的斜置，映像出现左右翻转与透视压缩。存在宽松角度停留区，不要求精密对准。

**我收到。** 首次进入比较区提交转镜观察，获得翻转；石膏像已亲看则提示“已获得新灵感”，意义提示沿用原稿O05。镜面中没亲点的像不代授物体。

**合理性。** “扭曲”解释为画法，不是宣称平面镜把物理像拧弯。近景保留原像一小部分与镜像同屏；若镜像效果不足以支持理解，先改善比较机位与主动来源提示，不擅自把原稿“扭曲”改名。

### P11 调查干画笔和已有碎镜

**我做。** 亲点石膏像前空桌面上的黑色干画笔，在近景看清黑色颜料和干涸笔毛，只记录黑色，播放原稿O06。原稿只要求检视，此处不再强加一次试纸拖画作为门槛。

**必要观察。** 已有碎镜片放在主画幅左下方安全区域的纸套中，完整留在画内，点击才获得锋利，介绍词使用原稿O08。手镜不必打碎，主线不出现砸镜任务，也不把破坏自己物件当成唯一创作途径。近景可看边口，不要求徒手拿取；不开真实物理碎裂系统。

**合理性。** 三个必要操作对应三个明确可见证据。保留原稿黑色加锋利的配方。碎镜片是这条配方的必要证据，直接使用桌上已有碎片，不要求打碎手镜；干涸只作为可见描述。

### P12 联系成柏影 并画入前景

**我做。** 固定＋翻转→扭曲；黑色＋锋利→粗犷；扭曲＋粗犷→柏影笔刷。成功预览是拉长、有折角的暗色竖影，结果说明仅使用功能性标签，不新增角色台词。画布上旧卷涡保留，柏影层位于它前面。

**我画。** 柏影默认直立，允许在整张画布内任意放置、旋转与叠放，不要求下端接底或覆盖前景。至少3笔可以提前收笔，默认5笔用尽本层颜料。材料说明给构图建议，但不当完成条件。

**我提交。** 点“完成绘画”。旧画层继续可见，缪斯先播放原稿阶段三台词组N04；结束后只逐步显色第三阶段已经接入交互的窗景、干颜料板和刮刀，外围和屋顶继续底稿。

**合理性。** 不要求玩家猜到要画柏树，倾斜或放到画面上方也是真实创作。图样名称、预览和落笔结果共同解释从性质到画法的转换。

## 七 阶段三 看向眼前的夜 并学会刮刀

### P13 窗口一直是窗口 不额外猜打开

**我做。** 点已显色的窗边。窗帘保留两侧收拢状态，不把旧拉帘作为重复谜题。近景有两处实际可点目标：“近处屋檐”和“远处灯火”；点任一先记窗这一物体，再在同一近景看另一处。

**我看到。** 夜空没有可辨星点，近屋遮住远屋的一角，几扇窗在大地上亮着。点近屋记录现实，点远景记录夜色，完成“离远看看”的窗灯比较后记录星辰意象。片刻推近只由此次点击触发，不接受滚轮缩放。

**合理性和衔接。** 两处证据都有真实画面，近远不会被一段诗句代领。窗边介绍词使用原稿O09。亲看“离远看看”后播放原稿O10，记录地面灯光引出的“星辰”意象；支持现实＋星辰→当下，不声称夜空已有实际星点。

### P14 干颜料板造成一个可理解的小困难

**我做。** 点干颜料板，看到颜料已经结壳，介绍词沿用原稿O14；再亲点“细看颜料”，取得混乱并播放O11。凝固只作为可见状态，不增加无配方用途的灰词。试图用画笔取色时只留一道划痕，不能取出湿颜料。没有先要求把抽象“擦除”合到调色板上。

**我看到下一步。** 刮刀就在板右侧，刀柄完整可见；物件旁有一小块原本露出的木色，暗示可以刮掉表层。悬停只显示“调色刮刀”。

**合理性。** 玩家有当前目标和合适工具，不从突然出现的“清洁”按钮跳到表面变白；颜料板不作为现实之夜的全部解释。

### P15 刀刃刮开干色 立即记住结果

**我做。** 点刮刀，以默认刀刃模式在试区拖一小段。接触后干颜料先裂成薄片并退出接触带，木色形成宽度明确的干净痕。3段短点按也能沿同一宽路径完成。

**我收到。** 有效接触约占试区长度40%时提交刮开动作，立即记录露出的底色与“刀刃揭底”的经验。首次反馈只显示操作结果“已刮开干颜料”，角色介绍词沿用原稿O12。不要求再点木纹取观察，不授屋顶或房间。

**合理性。** 干颜料碎屑只做表现，不制造物理灾难。工具经验来源真实，未来迁移有依据。半途取消保留可见痕迹但未达提交时不刷完成；继续同一试区即可。

### P16 翻刀面推开残留软色

**我做。** 同一近景看见板边一小团尚软颜料；按界面短提示切“刀面推色”，拖过小团。颜料铺薄并连接旁边色带，木底没有被继续挖开。刀刃与刀面的图标、光标角度不同。

**我收到。** 记录推色经验；工具模式可回看。此时刮刀留在工具位，不是一次性道具。

**合理性和衔接。** 同一工具的两种接触方式先在无后果的小试区学过，最终不会突然让玩家判断“刮刀为什么能涂色”。切模式来自近景工具条，右键仍统一返回，避免一键两义。

### P17 合成夜城 画出地面的灯

**我做。** 在笔记提交混乱＋夜色→肉身、现实＋星辰→当下，再提交肉身＋当下→第三阶段笔刷。前两条沿用原稿，最后一条是原稿缺项的补全设计，图样严格使用3.png。若我先合成出笔刷再试刮刀，画布仍可落笔，但阶段完成控件会明确显示“先在颜料板试过刮刀的两面”，并可点开来源定位；不会隐藏最后一个门槛。

**我画。** 默认预览提示夜城可以靠下放置，但整张画布均可作画，允许盖过柏影。至少3笔可以提前收笔，默认5笔用尽颜料。层按实际提交顺序叠加；系统不为拼成标准答案而偷偷把玩家笔触移到树后。

**我提交。** 当前层至少3笔、刀刃和刀面均亲试后，点“完成绘画”。画室保留此前物件实色，先播放原稿阶段四台词组N05，结束后才显色未燃油灯与取火工具；点灯后接N06。屋顶单独等待试刮许可，不能在第三阶段自动露出。

**合理性。** 第三阶段有两条并行线：窗景提供画面内容，颜料板提供最终工具。门槛清楚显示，顺序不限。肉身与当下是原稿第三阶段所需概念；其他无关观察不阻塞。

## 八 阶段四 点亮和两种主动收束

### P18 点左侧油灯 不是猜点亮加哪个物品

**我做。** 亲点左侧未燃油灯近看。火柴盒紧贴灯座，裸露灯芯与砂纸都可见。点盒取火柴、沿砂纸拖或点按划燃，再点灯芯。火柴不设短促倒计时；离开近景自动安全熄灭，可无限取用，不制造时间挑战。

**我看到。** 火柴头先碰砂纸才发光，再接触灯芯，火苗立即接上，桌面与墙面暖亮区在0.2秒内起变化，随后约1秒稳定。自动记录温暖、明亮和点灯完成，反馈“灯芯亮起来了”；无需再点油灯领结果。

**合理性。** 现实目标来自未燃灯、火柴与接触关系。抽象配方只用于创作暖星，不再把点亮当作万能钥匙，旧点灯精细接触可复用，倒计时和反复瞄准要简化。

### P19 暖星成为最后一层

**我做。** 新灵感提示只说明“可形成最后一支笔刷”，不另写缪斯台词。温暖＋明亮→暖星笔刷；到画布上部点或拖。至少3笔有效暖星图样即可提前完成；4.png每次落笔含有多少星形不当作笔数，默认6笔用尽本层颜料。位置与重叠自由，灯窗不冒充玩家的新落笔。画布从冰蓝动势、柏影、夜城到暖星的层次此时完整。

**我收到。** 达到三笔后，左侧工具位开放最终刮刀，功能提示“用刮刀涂抹画布上的颜料”。右上仍是原稿的“返回画室”和“完成绘画”；完成按钮还需本次刀面涂抹完成才允许普通收束。可以继续消耗余下颜料，也可先选刮刀。没有隐藏结局选择弹窗。

**合理性。** 普通完成是玩家正向选择，不是没找到隐藏秘密的惩罚。星印发光只影响画布局部，不让房间突然换成另一个画风。

### P20 第一次异常 玩家不用抢时间

**触发。** 油灯被点燃后，主画幅上沿木梁附近出现短促冷蓝反光，和暖色灯光方向不同；声音很轻。若玩家仍在灯近景，先只留下事实和持久细痕，回到主视角再播放一次反光提示。

**我看到。** 一小道蓝灰底痕一直保留，像被擦开了漆层。它没有悬浮任务标记，悬停到真实细痕区域时出现极淡局部边缘，不给整片屋顶发光。之前的暖光与此处冷色形成可见差异。

**合理性。** 不强制看屋顶，不自动移动镜头，也不要求我用没有的转头操作。错过闪光仍可发现细痕；这解决原稿短时暗示与近景互相冲突的问题。

### P21 刀面收色 与第二条跨表面证据

**我做。** 在画布选择刮刀，默认刀面。沿现有厚色边推一小段，看到孤立笔印连为一片，旧构图仍在。至少一条有效收色笔划即可，3次辅助点按也可。

**我看到。** 同时有一次极轻的纸面剥落声；返回主画面后，屋面细痕多出一小段，与刚才推刀方向相似。不是把玩家画的完整图形投到屋顶，也不弹“试试屋顶”。

**我能选择。** 刀面涂抹完成后，右上“完成绘画”可提交普通结局；也可点它上方的“返回画室”继续调查。没有另外一套“就留这张／再看看”大面板。涂抹动作不自动结束，保留返回窗口。

**合理性。** 玩家已经学过刀刃揭底，现在通过同向痕迹意识到另一表面可能有同样关系。隐藏内容需要有可追溯证据，而非单纯挑战玩家像素搜寻。

**返回创作。** 如果涂抹后继续落笔或撤销，当前层按有效笔触重新呈现，并提示再次用刀面收色；单纯返回画室不会清掉涂抹。撤销到不足三笔时，两条路线的最终操作均恢复最低笔数限制。

### P22 常规结局 重新点亮

**我做。** 亲点右上“完成绘画”。立即锁定普通结局，取消未开始的其他收束。画布保持我实际画下的结果，暖光在房间慢慢稳定，镜头只做轻微预设靠近，不用另一张成品图替换我的画。

**我听到。** 缪斯使用原稿常规收束台词组N07。约6秒后淡出，显示“重新点亮”。不出现失败、嘲笑或未找到真结局之类评价。

**结束操作。** 结束菜单提供“重新开始”“从第四阶段再试”“退出”。从第四阶段再试是内存中的明确练习快照，不保存到硬盘；恢复阶段四开始、前三层画面与实际已知材料，清掉本次点灯、屋面调查、最终落笔和结局选择。按钮旁说明“回到点灯前，保留前三层作品”。

**合理性。** 普通结局得到完整认可。已点击普通定稿后不能再被隐藏线抢走控制，避免两段演出争抢输入。

### P23 亲点异常 屋面才成为已知对象

**我做。** 在任何尚未定稿的阶段四时刻回到主画面，亲点细痕。进入预设屋面近景。取得屋顶物体和屋面表面观察；内心OS沿用原稿：“……原来这里也可以被触碰。”不出现“隐藏结局”或“离开房间”的解释。

**我看到。** 近景清楚保留木梁、灰泥和一小段已露蓝底；工具位里已有刮刀。选择刀刃时光标出现同样的接触预览，未选时点击只调查。沿用原稿：先在笔记选择已取得的屋面，再拿刮刀用于该表面；选择只确定目标，不代替亲手接触。

**合理性。** 名词和物体分离，只有实际点击才记录屋顶。把熟练工具用于已观察表面，比“擦除＋屋顶”更有可执行性。仅发现屋面不锁普通路线。

### P24 先试刮一小片 再主动越过边界

**我做。** 第四阶段已至少落三笔后，以刀刃在细痕上拖过一小段。尚未画满三笔时可以调查屋面，但工具提示先完成本阶段最低落笔数，不能用隐藏路线跳过绘画。接触后0.2秒内露出深蓝夜色，木梁保留；第一段有效划痕只形成一处小孔，不立即瓦解全屋。记录屋面试刮，自动获得“屋面下的夜色”观察，不自动授天空物体。

**我选择。** 此时可放下刮刀回到画布，普通结局仍可提交。第四层仍至少三笔时，继续在新露出的边缘拖出第二段有效揭底，才提交隐藏线锁定事实，取消普通完成入口。预览以更清楚的开口和轻风声提示正在扩大；没有选择结局的弹窗。

**合理性。** 把无意试触与主动继续分开，避免第一次尝试就不可逆地抢走普通结局。第二次是迁移已知动作，玩家能说出“我要继续刮开它”，不是被系统判断心态。

### P25 屋顶开了之后 还要亲自看见房间

**我看到。** 屋顶局部先显露普通夜色，开口后显现项目已有星空材质及其流动效果，不把玩家画布笔印再生成或映射成一套新星空。外围木梁清楚、房间未崩塌。镜头缓缓回到能够同时看屋面与墙面的预设主构图。

**我做。** 亲点开口，取得天空；再亲点横跨灰泥、木框与帘布的一道连续笔迹，获得“接连的笔迹”。这道笔迹在稳定后一直留着，无5秒抢点限制。

**我理解并继续。** 此处不新增解释性独白。这时我仍需亲点画室另一处可见表面，如窗下墙；获得房间物体，工具出现“沿这道笔迹继续”。这不是系统自动授房间，也不要求我从抽象词表中猜“世界”。

**合理性。** 保留当前项目“接连笔迹调查后亲点房间”的边界；从小孔到全屋有两次新的主动观察。若我中途停下，房间保持可看、可继续，不自动播放整段终局。

### P26 最后一划 星空涌现

**我做。** 用刮刀刀刃在已调查的窗下墙沿连续笔迹拖一段有效划痕。此动作提交房间擦开事实；从本次接触向墙、桌边、地面依次扩展统一笔势。家具逐渐失去实体边界，仍保留短暂木梁剪影，不模拟碎楼坠落。

**我看到。** 现实路线沿用当前星空材质、流动和固定画幅效果，不重新设计星空。约10至14秒后房间边界让出完整星河，停留约3秒，可通过暂停菜单继续观看或主动结束。无解释性长独白。

**结束。** 主动结束或演出收束后淡出，显示“星之河之外”，与常规结局等规格排版。菜单同P22。隐藏线不能覆盖已经提交的常规结局；先提交的终局命令在领域层互斥。

**合理性。** 每次大变化前都有玩家接触与可见结果。世界展开来自玩家持续行动，不来自“过了几秒就赐予”的线索或演出。

## 九 每种卡点的恢复路径

| 玩家行为或困惑 | 游戏给出的恢复 | 不允许发生的结果 |
| --- | --- | --- |
| 没读便条就先观察杯水 | 直接允许；便条可随时补读，不重播开场 | N01结束后还被隐藏的便条门槛卡住 |
| 先点笔再点杯，先看蜡笔画 | 各自记录自己的来源，材料齐后同样出现灵感 | 固定点击顺序导致配方永久不可用 |
| 动作后没再点结果 | 结果观察随有效动作提交，笔记有未读提示 | 洗笔后再点水、点灯后再点灯芯才领条目 |
| 材料齐却没懂怎么合 | 来源回看→关系描述→用户主动展开材料建议 | 自动把答案塞满画布或静候倒计时解谜 |
| 尝试放入第三项 | 保留前两项并拒绝第三项；不自动替换 | 界面放入三项但后台偷偷只取两项 |
| 没懂画布不是自由画 | 第一次预览显示原始图样，一次按下松开只放一枚 | 使用自由绘画文案却只能盖章 |
| 连续原地点按 | 每次有效落笔都消耗颜料并计数，允许重叠 | 系统因认为“不好看”否认玩家落笔 |
| 尝试把最后一笔调得过小或过大 | 落笔前大小范围已按剩余预算收窄，预览与提交一致 | 松开后突然放大，或颜料不足却仍扣出负值 |
| 返回或Esc打断拖动 | 收笔，保留已提交有效笔划；未提交工具接触取消 | 无鼠标松开事件而永久绘制 |
| 打开笔记再返回 | 保留临时选词与当前层，不重新播放教学 | UI重开清空作品或替玩家提交 |
| 屋顶闪光时在近景 | 记住待展示反馈，主视角复现一次，细痕持久 | 一次性线索已播完导致隐藏线失效 |
| 已发现屋面但想普通结束 | 未完成第二次屋面揭底前允许返回定稿 | 调查本身就被当作路线选择 |
| 在刀面模式拖屋面 | 只见轻痕，短句“刀面只是推色”，可换刀刃 | 所有工具模式都触发同一擦除事实 |
| 接触打断后回来 | 原进度可续；无效输入不发完整动作 | 画面完成但领域没完成，或反过来 |
| 两个结局输入近同时到达 | 应用层按接受顺序原子提交，已终局拒后续 | 两套结尾同时播放、字幕互相覆盖 |
| 重开或从最终段再试 | 取消旧协程、输入捕获、声音、RT历史和全局Shader参数 | 旧演出几秒后在新局里出现 |

## 十 旁白和节奏不抢走操作

旁白按《09 原稿台词与触发表》的N01至N07触发。字幕换行按可用宽度排版，不为了造节奏擅自拆开完整句子。原稿台词完整保存在集中表中，采用文本只做表内列明的最小删节和标点调整；按原稿已有段落分段触发，允许继续操作，不强制玩家等整段播完。缪斯只谈我已经看见的内容；不能在我没点灯时说灯已亮，也不能主动提屋顶、房间边界或隐藏路线。

物件内心话显示在物件左侧的独立节点，最多两行；缪斯沿用原稿image1的左上旁白区域，两者不同时抢读。新操作优先于闲谈，操作反馈优先于环境独白；结束语高于普通内容。关键提示不会被普通碎片提示替换。暂停冻结语音和时间，打开笔记降低环境音，不继续堆十句旁白。所有一次性触发按会话记录去重。

首轮节奏预算：开场1至2分钟、阶段一4至6分钟、阶段二4至6分钟、阶段三5至7分钟、阶段四及普通结尾3至5分钟；主动隐藏线额外3至5分钟。合计约17至26分钟只是设计预算，不能写为已验证游玩时长。若试玩显著更长，先减重复合成与近景往返，不加跳过玩家实际观察的自动授予。

## 十一 玩家视角验收

每个步骤在上文均写出“看见什么、为何会做、实际输入、立即反馈、怎么继续”。桌面评审已对顺序、证据、配方和终止条件作闭合检查；是否自然仍须由没有读过方案的人试玩验证。

建议至少5位首次玩家分别走普通线，另外3位在不告知屋顶答案的情况下观察隐藏发现。主持人不出声提示，只记录停顿和玩家原话。目标为：大多数人在首次洗笔后能说出材料已经记下；第一轮两次失败后能找到主动提示；每层完成前能说出还缺什么；没人因错过闪光而失去隐藏入口；普通结尾玩家不认为自己失败。隐藏发现率不设100%，但发现后的操作理解率应接近全部，不能把看见异常之后仍靠穷举当成隐藏难度。

若一个必要动作必须由主持人解释，返回对应P步骤修改目标摆放、反馈或措辞。不能用“玩家不认真”关闭问题。后续问题闭环与测试用例见《06 问题闭环与验收计划》。

已实看蜡笔画.zip中的BaseColor：当前是褐色旧纸上的人物绘画，不是原稿描述的鲜艳奔放画痕。纸张模型可复用，正面画面由美术替换为符合原稿的蜡笔线条；不在临时概念图里自行确定房子、人物或其他新叙事题材。未完成替换前，文案和笔触性质的视觉证据不算验收通过。
