# 第二阶段实现与逐物件显色

2026年10月20日。本批接入P08至P12，并按冻鱼最新要求收紧全部阶段的显色时序。首阶段既有演出已由冻鱼确认满意；本批新增内容仍等本次实际运行检查及人工验收，不沿用独立TA验收结论。

## 当前可玩范围

首阶段保持杯笔接触、蜡笔画调查、三条配方及至少三笔主动收层。小画已替换为冻鱼提供的2048平方原始PNG，保留完整画面和比例，窗台位置、Logic与来源ID不变。

第一层收笔后回到主视角，先完整播放N03。旧物件维持实色，新物件仍为草稿；N03结束后，石膏像、完整手镜、干画笔及已有碎片在约1.4秒内显色，渐显结束才恢复输入。背景、右灯、书柜、窗景和屋顶继续保持底稿。

1. 点击石膏像，记录固定、苍白、规整，使用原稿O04。
2. 点击完整手镜进入比较近景。左右拖动镜面，或按左右方向键；最大±15度，主动转动达到±8度即可记录翻转。拿起不自动记录。镜面使用当前房间的真实反射，原像与镜像同屏；未亲点石膏不会代授石膏来源。O05仅在已经亲看石膏的比较中显示。
3. 点击黑色干画笔，记录黑色、干涸，使用原稿O06。
4. 点击桌上已有碎镜片，记录锋利、脆弱、错乱，使用原稿O08。不必打碎完整手镜。
5. 在笔记提交固定＋翻转→扭曲、黑色＋锋利→粗犷、扭曲＋粗犷→柏影笔刷。
6. 点击原画布，在第一层作品上使用原始2.png叠加柏影。默认5笔合法耗尽100单位；第三笔起可以主动提前收层，余量明确放弃。回到房间再进入，作品不丢失。
7. 完成第二层后播放原稿N04。本批止于第二层及N04交接，第三阶段窗景/刮刀及第三支笔刷尚未接入；没有用空白占位任务冒充第三阶段已完成。

## 显色与输入的共同边界

| 时点 | 显色 | 输入 |
| --- | --- | --- |
| 进入场景、N01整组播放中 | 全底稿；保留既有退黑、短失焦、轻重影 | 全部关闭，笔记入口隐藏 |
| N01完成后 | 首阶段七个Renderer逐步恢复实色 | 渐显完成后恢复 |
| 第一层完成、N03播放中 | 首阶段保持；新阶段仍为底稿 | 全部关闭 |
| N03完成后 | 只新增第二阶段物件 | 渐显完成后恢复 |
| 第二层完成、N04播放中 | 前两阶段保持；不提前恢复整屋 | 全部关闭 |
| N04完成后 | 只允许第三阶段已实现的明确目标；本批清单为空 | 交回操作，下一阶段尚待接入 |
| 以后第四阶段 | N05结束后只新增点灯所需目标 | 同一时序交接 |
| 以后屋顶 | 第四层至少三笔、屋顶试刮许可成立、相关N05/N06已结束后，独立渐显 | 不提前提供屋顶拾取或金丝 |

屋顶不属于第二、三、四阶段的普通显色清单。`RestoreStage(4)`也不能解除屋顶遮挡；后续屋顶流程必须在真实许可及旁白完成后显式调用独立入口。本批没有添加屋顶事实、屋顶清晰Renderer或屋顶交互。

实际底稿通道每帧冻结最多32个Renderer世界包围体及显色权重，跟随物件移动；没有扩大到整片桌面/墙面的清晰盒。背景遮挡保持1，显色只改变物件内部的混合权重。RenderGraph的复用计数逐帧归零。演出只更新视觉，不授物体、不补调查、不伪造便签阅读。

## 实现归属和UI联调

- `AtelierFlowRules.CreateOpening()`当前内容已扩至前两阶段；第二阶段来源以第一层主动完成为领域前置。手镜比较动作要求来源已亲点，拿起、等待和截图不授翻转。
- `AtelierFlowGameplay`新增只读`IsStageTransition`，`GameplayInputEnabled`同时覆盖开场、阶段旁白及显色。UI统一读取后者，不能只判断`IsOpening`。
- `AtelierDraftCamera`保存明确的首阶段、第二、第三、第四阶段和屋顶Renderer清单；三四阶段未接入时为空，不以层数增长恢复整个房间。
- `AtelierFlowMirror`拥有手镜拿起/放回、输入捕获与±15度限制；反射RT、材质和网格仍归镜面组件释放。主镜头后处理保留。运行时反射由追加的`AtelierMirrorFeature`在后处理后、金丝与Overlay前绘制真实网格，按当前深度保留前景遮挡，有限LDR色调映射避免反射再次参与Bloom。实时反射也复制主镜头的显色许可，不能从镜内提前看清屋顶或其他未来物件。镜框和背衬使用独立有限亮度材质，原独立TA路径不变。长物件介绍暂沿用调查框按完整句分页，不截断整段；正式笔记详情仍归UI同学。
- `AtelierFlowStageTwoBuilder`只通过Editor API修改开发副本、图片材质与本批Prefab，拒绝覆盖未保存场景。小画PNG原样保留，干笔新增独立视觉Prefab，Logic不写入视觉母版。
- 画布Session、命令、RT、四层颜料协议不变。正式Workspace、笔记笔刷页、新词提示、首次导读继续由UI同学完成，见[04](<04 UI开发交接与画布工作.md>)第十五节。

本批继续提交到`codex/atelier-scene-flow`，不推送UI分支。UI同学保留自己的分支与提交，需更新联调代码时正常合并场景分支，由我们负责主场景装配。无须重做画布底层。
