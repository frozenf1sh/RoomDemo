## 本案采用的规则

四张原始PNG逐层累积在同一画布上。位置、旋转和叠放自由，没有覆盖率、指定分区或审美评分。每次按下到松开只落一枚图样；阶段默认笔数为6、5、5、6，颜料各100单位，每笔12至24单位。预览时就收窄合法大小，保证最后一笔仍在上下限内并耗尽颜料。第三笔起允许提前收层，余量放弃且不结转；0至2笔不能跳过。

第四层第三笔后开放最终刮刀，刀面涂抹后主动点右上原按钮“完成绘画”才进入普通结局；返回画室仍可调查异常。隐藏线也检查第四层至少三笔，首次屋面试刮可返回，第二次主动扩刮才锁定隐藏路线。之后亲点天空、接连笔迹和房间，再亲手刮墙。

台词优先采用原稿，只有列明的最小删节、标点调整和必要功能提示。画布控件位置以原稿image3为准，笔刷以原始PNG和image4为准。阶段图决定遮挡范围，未完成底稿只替换这些局部区域的模糊质感，不能重绘整间房。

现实路线直接使用项目现有星空材质与运行效果。用户指出的两张星空生成图已退出采用，不再据此改造星空；原始生成文件保留，图册不再展示。

## 已完成与实施范围

设计、UI交接、概念图和独立画布原型已交付。[五份独立TA验证副本](<11 TA验证场景与验收.md>)已由冻鱼人工确认通过，手镜转角限为±15度，基线提交为`8eef425`。本批开始将局部底稿、杯口散色与P00至P07接入AtelierPlayable；首层已由冻鱼确认满意；最新开场与UI交接以[13 修订](<13 第一阶段优化与UI接手基线.md>)为准，前一批证据保留在12。二至四阶段、双路线和正式Workspace尚未完成，不能把独立TA验收当作完整主流程验收。

工程中已通过Unity Editor API实际新增并连接71个Prefab，保留AtelierPlayable的现有层级和玩法。迁移前、连接后及重开后均为1888个展开对象，169551项数据比较一致。当前场景编译、会话启动、关键引用、笔记开合与运行错误检查通过。正式AtelierNight、Build Settings及用户原有QualitySettings保持原样。详见[迁移报告](参考资料/Prefab迁移报告.json)和[运行检查](参考资料/Prefab运行检查.json)。

原型的脚本和预算模型已做自动校验：[脚本校验](参考资料/画布原型脚本校验.json)、[预算校验](参考资料/颜料预算模型校验.json)。交付文件的链接、原图字节、Prefab元数据及保护文件核对见[完整性检查](参考资料/交付完整性检查.json)。没有完成浏览器视觉验收、新流程的真实构建UI验收、配音听感或真人鼠标试玩，不将这些写为通过。概念图不作为运行效果或可直接导入的天空/笔刷资产。

## 已确认的美术缺口

“蜡笔画.zip”实际贴图是褐色旧纸上的人物画，与原稿要求的鲜艳、奔放笔触不符。纸张模型可复用，正面画面需美术替换。图册里的小画只标位置，不确定新题材。模型包未含完整来源许可信息，记录见07；设计交付时未导入模型；后续TA实验只导入石膏FBX到独立验证目录，未导入其大型贴图，见11。
