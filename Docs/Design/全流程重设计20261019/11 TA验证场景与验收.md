# TA验证场景与验收

2026年10月19日。这批是五份独立视觉原型，使用当前画室副本和固定镜头。用于冻鱼逐项看效果、决定调整方向；不接新流程，不写GameState，不替代正式UI，不改变正式Build Settings。UI同学继续在`codex/atelier-four-stage-ui`开发；本批在`codex/atelier-scene-flow`。

## 怎么打开

最快方式是打开项目根目录`Builds/AtelierTAProbes20261019/TA验证演示.app`。演示底部可直接切换五项。构建是本机验证产物，不纳入Git。关闭应用用Cmd+Q。

Unity里从菜单**游戏 → 技术美术 → 四阶段TA验证 → 01 局部草稿遮挡**进入，按Play；其余四项也有独立菜单。首次创建可用“创建缺失验证场景”。“重建五份验证副本”会覆盖本工具生成的五个实验场景和两个椭圆网格；调整过验证场景后先保存自己的副本。所有操作遇到未保存场景都会停止。

通用控制：`H`隐藏／显示面板，`F`主视角／固定近景，`R`复位，空格暂停视觉时间。暂停不暂停UI，可以继续切换场景。草稿阶段用`0`原场景、`1`阶段一、`2`阶段二、`3/4`全景。面板始终是开发工具，不是正式游戏HUD。

## 实现和限制

草稿使用独立URP RenderGraph Feature，从真实深度恢复世界坐标，圈定左侧空间和窗后区域，再叠加稳定的炭线、灰纸与轮廓。其他区域保留原材质。它验证范围、暗度、过渡和近景稳定性，正式接入仍应改为可配置Renderer分组，处理窗框、透明帘和悬停金丝的边界；本批没有开放任何调查权限，也不能证明未来物品无法被点击。

洗笔复用现有杯、水面和画笔。色带为有限程序化色丝，不是完整流体模拟；反馈由几何笔尖与真实液面高度相交触发。没有手部和接触声音。先确定近远景可读性，再决定是否需要真实平流。

手镜512平方LDR RT、15Hz真实平面反射，标准URP Unlit采样自有RT，并按真实镜头投影更新有限椭圆网格的UV。当前三角片内插存在近似，尚未验证大角度极端畸变；原型不作光学精度承诺。镜像摄像机排除镜面层和天空源层，退出时释放RT与隐藏摄像机。**手镜验证场景暂时关闭主镜头后处理，解决构建中镜面合成被后处理放大的问题；完整后处理兼容尚未通过。** 镜框、镜柄和镜面是轻量占位模型；石膏使用策划FBX和单一石膏材质。镜子是完整镜面，不做打碎玩法。

刮刀使用最多64段路径。左侧干壳、右侧湿色是独立测试材料；刀具是简单占位。此处验证视觉差异，不代表画布作品的图样合成和刀面混色已经接入。

屋面只裁剪原有两层屋面Renderer的颜色、深度、法线与阴影。背后调用现有LivingSky与固定画幅星空，不重做星空。实验没有游戏碰撞、调查或隐藏线锁定；正式接入需统一点击许可和可见孔洞，不能据此宣称全屋擦除新流程已完成。

五份场景由已保存的AtelierPlayable副本生成，旧玩法和Canvas禁用，原美术仍保留。实验管线克隆现有Renderer及其Feature，只在验证运行时覆盖Quality的管线引用，退出后恢复。生产Renderer、正式场景、正式构建列表和用户原有Quality设置不写入。

## 验证记录

自动检查和截图保存在本机`Logs/TAProbes20261019/`，其中`运行检查.json`记录五份场景、复位和Shader错误；`Captures/`为世界画面；`Player验收版/`为修复后的实际构建连同中文面板的画面。检查只支持编译、运行和画面存在，不证明美术、鼠标手感、性能预算或首次玩家理解达标。

第一轮实际Player切场景时出现GPU Resident Drawer无效批次错误；该问题在Editor离屏检查中没有暴露，不能仅凭C#回调中的“0错误”判定构建正常。实验运行时复制一份管线，在自有副本内关闭GPU常驻批处理；退出释放副本，原管线资产不改。构建复用现有变体，不为快速验证重新编译整批非GPU批处理变体。最终检查同时看渲染线程回调、原生日志和实际截图。


已完成实际macOS构建、五场景连续切换、复位自动检查和中文面板截图查看；最终运行错误回调与原生日志批次失效均为0。构建仍有未启用景深/投影变体裁剪、阴影图集降级提示，没有把它们写成“Console零提示”。[运行记录](参考资料/TA验证/TA验证运行记录.json)给出保护文件和已知边界。

验收后由冻鱼指定保留／修改项，我们再接主场景。建议先定P0-1和P0-2，避免先把全部流程绑定到尚未认可的遮挡与接触反馈。
