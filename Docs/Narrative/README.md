# 画布与房间：第七阶段

旁白希望所有想法都留在画里。玩家通过相同的解释动作，逐渐发现画布并非唯一合法目标；没有听话／反抗选项和路线进度条。

试玩包：[macOS 画布与房间](../../Builds/RoomDemo-画布与房间-macOS.zip)，附字体、模型许可及简明操作说明。

## 两条路线

| 阶段 | 留在画布 | 进入现实 |
| --- | --- | --- |
| 生长 | 画内出现树与枝叶 | 盆栽开始舒展，次日繁茂并碰落书 |
| 远方 | 画内加入地平线，显露海的草稿 | 窗外打开，引风显露草稿 |
| 海 | 在框内形成静止海景 | 同一个海画解释在旧现实意义存在时外溢，植物和窗继续反应 |
| 星空 | 完成画内夜空，安静淡出 | 只打开屋顶；再亲点边界，第一次认识“房间” |
| 森林 | 不进入这段现实探索 | 树影 + 风声形成森林，森林 + 房间打开边界，营火最后出现 |

两条路线都从新游戏开始，前置观察仍是亲点新芽和书中“向光”。画布解释留下共同的次日书页入口，服从者无需先把盆栽改变才能继续探索。
连续三个核心服从解释且从未偏离才收束；重复配方不计数，有过偏离不再强制锁回画布。房间在屋顶成立、至少两次偏离后才可发现，而且必须亲点。

## 纸面与旁白

N 打开笔记，所有材料依获得顺序排在左边，可以滚动。拖到中央、重新摆放或拖回；点击也可放入／移回。最多三个活动词条。所有近邻组合都可以尝试，淡线不是正确答案指示器。只有实际成功才留下关系。
左侧旧笔迹明确写着“画 ← 这里。”，在初期较明显，偏离后渐淡。形成概念仍有逐字书写与少量光点。

世界字幕是“发生了什么”；旁白是“应该怎样”。两个文本节点分别排版。旁白支持打字、轻声音、`[pause=0.8]` 自定义停顿、优先级、小队列、打断和每局一次。没有头像或对话框。
普通结局看完作品后淡出，只显示“完成。”；Esc 仍能重开。现实结局保留家具、屋顶星空、森林和最后营火，不再给哲学结论。

## 内容修改入口

- `Assets/_Game/Runtime/Domain/Rules/NarrativeRules.cs`：配方倾向、画内产出、共同探索、房间门槛与结局条件。核心引擎不含具体叙事文本。
- `Assets/_Game/Runtime/Unity/Narrative/NarrationDefinition.cs`：事件身份、中文短句、停顿、延迟、声音、优先级与一次性播放。
- `Assets/_Game/Runtime/Unity/Content/MainlinePresentation.cs`：世界字幕和配方的声音／微粒／序列入口。
- `Game.Editor.NarrativeSceneSetup.Apply()`：增量同步旁白、画布、词栏与序列化引用，拒绝未保存场景。
- `Game.Editor.NarrativePainterlyPass.Apply()`：家具与外景共用笔触调制、专用星夜纹理、慢速流动与稀疏空气光点；风格强度只属于表现。

旁白不增加世界事实。主题、天空、笔触和演出时间不进入 GameState。恢复先还原历史倾向再计算闭包，避免混合路线被误当成纯服从路线。
本轮未下载新第三方模型；沿用已有许可表。新星夜底图由内置 imagegen 生成，来源与提示见 [生成说明](星夜底图生成说明.md)。字体及已有第三方许可证继续随构建分发。

## 验证与边界

2026-10-05 统一流水线通过：编译、59 项编辑模式、29 项运行模式、场景验证和 macOS 构建。最后修正房间提前悬停以后，另复测 11 项探索回归、屋顶前后实际射线入口并重新验证／构建；没有修改领域规则。Unity 远程工具包在试玩程序中保持禁用，构建会提示未配置其 RuntimeConfig；正常玩法不依赖它。本轮专用 Shader 没有编译错误。

两条原生路线都由新游戏开始，画布路线 40 项、现实路线 46 项走查通过。走查使用场景射线、近景热点、UGUI 拖动／按钮和暂停菜单，不使用预设、调试授予或手工修改状态。正常原生窗口另检查了 N 开关、Esc 暂停、鼠标亲点进入检视和菜单重新开始。
它验证可达性和输入适配器，不能证明陌生玩家是否惊讶、普通结局是否空、或是否自然理解房间成为画布。两条路线的真实鼠标手感、音效听感与叙事情绪仍需不知答案的玩家试玩；不虚构验收答案。
