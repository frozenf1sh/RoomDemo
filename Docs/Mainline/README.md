# 第六阶段主线与笔记本

已把生长、跨日、海画和世界重构接成同一个新游戏流程。星空是第一段世界解释，森林是第二段，营火自动留在最后；F7 完整样板继续作为开发预览，正式流程无需使用它。

## 怎么玩

1. 第一天亲点盆栽和新芽；拿近书、打开、翻页并点向光。拖动两条观察到笔记中央形成生长，再把生长与盆栽靠近并解释。从 Esc 菜单结束今天。
2. 第二天检视落地书第三页的地平线，亲点窗，解释远方与窗。点击风吹出的纸、亲点画，解释海与画。看完既有涌现，再结束今天。
3. 第三天亲点天花板和窗外，收集夜色与无边，联想星空，再解释星空与天花板。屋顶打开，墙还在。
4. 重新亲点窗外收集树影，点脚下房间收集风声。联想森林，解释森林与房间。树林先出现，营火最后点燃。

## 笔记本 V2

N 打开／关闭；词条可从边栏拖入中央，自由移动，拖出中央区域移回。点击也能放入或归还。最多三个活动词条，收藏不会被消费。相邻词条存在尚未完成且前置条件满足的精确配方时显示淡线与小按钮：线索产出为“联想”，事实产出为“解释”。三个词都靠近时按三词精确匹配，不截取两词答案。成功联系仍记录在纸页底部。

获得细节有局部少量光点与轻声音；形成概念有纸面连接、少量墨光与书写；解释生效后收起笔记，字幕淡入一行并自动淡出。新发现提醒只持续到打开笔记，H 帮助也是临时文字。正式画面不恢复标题、日序或大按钮。

## 怎么追加内容

- 玩法数据：`Assets/_Game/Runtime/Domain/Rules/MainlineRules.cs`。增加线索、来源观察、配方与反应。物体线索只能通过自己的发现来源获得。匹配和闭包不需改引擎。
- 表现数据：`Assets/_Game/Runtime/Unity/Content/MainlinePresentation.cs`。按 RecipeId 配置可选 Subtitle、AudioCue、VfxCue、SequenceId；字幕系统本身不认识星空或森林。
- 声音资源与音量：`MainlineSceneSetup.InstallFeedback` 的 Cue 表。现有三类反馈复用轻声音；新增声音只补 Cue，不在热点或 Presenter 散落资源引用。
- 既有导演入口是 `ceiling_starry` 与 `forest_world`。只有新增具体演出时才注册新的入口；普通字幕、声音或概念不需要新增导演。
- 更改内容表现绑定后，在退出运行模式、保存人工调整的条件下调用 `Game.Editor.MainlineSceneSetup.Apply()`，随后保存并验证场景。它不重建房间美术。
