# 历史可玩切片真人试玩验收

> 本文记录旧主线各阶段的验收问题，不是当前 `AtelierPlayable` 的操作说明或验收结论。当前流程见[玩法流程](Design/玩法流程.md)，实施状态见[画室玩法实施记录](Design/画室玩法实施记录.md)。

状态：历史记录。下方旧切片、海画和第四阶段记录只说明当时版本，不代表当前叙事情绪已验收。

## 当前版本：画布与房间

测试者从新游戏开始，不使用预设、开发快捷键或手动改状态。先不展示配方答案，也不告诉玩家存在“服从／偏离”计数。
记录首次卡点、主动尝试的目标和使用临时提示的位置。需要重玩另一条路线时，重新开始；不要把第一次观察经验伪装成第二名陌生玩家。

试玩后记录原话，不代填理想答案：

1. 第一次把生长交给盆栽后，旁白让你有什么感觉？____
2. 你是怎样发现想法也能交给画以外的东西的？____
3. 完成画后，你觉得房间发生了什么？这个结束让你有什么感觉？____
4. “房间”第一次进入笔记时，你意识到了什么？____
5. 两个结局给你的感觉有何区别？它们分别完成了什么？____

另外观察：是否分清世界接受解释的字幕与旁白的要求；书页、笔记拖动、跨日和声音是否自然；是否在不知道答案时亲自找到房间的轻交互入口。
自动路线从新游戏验证输入适配器和终态可达性，不能填入这些理解与情绪答案。当前没有陌生玩家的有效答卷。

## 历史切片记录

测试者应未看过项目说明的答案段，且不使用 F3 跳关。开发者的已知答案走查及自动测试只能证明功能。

记录：

- 从启动到 “房间记得。” 的用时：____
- 使用 H 提示的次数与阶段：____
- 第一次卡住的位置 / 认为可点击却不能点击的物体：____
- 是否看懂“生长”使植物长大、书自行掉落：____
- 是否察觉风是旧解释之间自动联系的结果：____
- 是否在“海 + 画”之后注意到植物和窗户自行改变：____
- 玩家是否说出类似“我没有再次选择植物/窗户”的理解：____
- 是否注意到新发现通知和笔记本按钮闪烁；打开后是否正常停止：____
- 未点击窗户或画时，笔记本是否确实没有它们：____
- 声音是否过响、突兀或不能区分：____

开发已验证：三次组合的实际窗口走查、动态海画、滴水、水渍、水生植物、海窗与临时提示。
发现旧引导面板在风进入阶段过早显示“完成”，已修正为继续调查纸张，并加入回归断言。
2026-10-04 重新走查独立构建：点击书仅获得书与远方，调查纸张仅获得海；窗户与画必须各自点击。新发现通知清晰显示，打开笔记本后未读闪烁停止，三次组合仍可到达结束提示。

若试玩短于目标，先检查观察文本、探索空间和提示是否过于直接，再调整现有三次组合的反馈与阅读节奏。
若长于目标，优先修复线索不可见、点击范围或提示误导。不要增加无关谜题或强制等待来凑时长。

## 第三阶段样片评审

海画样片已增加画、水、植物、窗外、房间氛围的连续节拍；技术结果与画面取样见 [演出样片验收](Benchmark/演出样片验收.md)。完整核心演出约 17 秒，随后自由观察，不强迫等待来填满 60～90 秒。

真人评审时，不提前介绍因果答案。观看后记录：

- 是否先注意到画的异常与海声：____
- 是否分辨出第一滴水是随后发生的独立节拍：____
- “你觉得植物为什么后来变了？”（原话）：____
- “刚才哪些变化是你直接做的，哪些不是？”（原话）：____
- 是否自发转向窗户、发现远方进一步变化：____
- 后半段是否感到意义正在扩散、世界开始自行回应：____
- 音量、声源方位与声音引导是否清楚：____

这些问题当前尚未收到陌生玩家的实测记录。自动复测、开发者已知答案操作和无音轨画面取样不替代它们。真人验收通过之前不扩展镜子、重量或翻转玩法。


## 第四阶段：探索、生长与星空

第四阶段当时的正式新游戏使用探索规则，点击盆栽不直接获得“生长”；这一边界仍保留。旧版本三次组合记录只描述当时版本。
技术复测由原生程序的真实房间射线、近景热点与笔记入口执行；它不能证明真人发现过程、鼠标手感或音效听感。

### 案例 A（不要预先告诉答案）

让未参与实现的人从新游戏开始，默认玩家模式，不使用授予、预设或开发面板。记录卡点与提示次数：

- 能否发现盆栽可以仔细看，并尝试旋转、缩放：____
- 新芽是否太难发现或过于醒目：____
- 能否打开旧书、翻页并发现“向光”短句：____
- 拖转是否误触细节；点击、缩放、返回是否符合预期：____
- 新发现通知是否清楚；笔记按钮闪烁是否吸引注意并在打开后停止：____
- 是否区分“记下的细节”和“想出的意义”：____
- 联想得到生长后，是否知道还能把它作用于盆栽：____
- 是否主动选择结束今天；是否注意到次日繁茂与落书：____
- 未亲点窗户、画之前，它们是否一直未出现在笔记本：____
- 声音的音量、方位、书页与跨日余音是否适合：____

试玩后询问并记录原话：

1. “生长这个想法是哪里来的？”____
2. “一天过去以后，你期待发生什么？”____
3. “刚才哪些变化是你直接做的，哪些不是？”____

理想理解是把植物上的新芽和书中向光的描述联系起来，再让解释经过一天继续改变房间。不要以玩家猜中配方代替这个理解。

### 案例 B（独立星空样板）

由实现者准备“星空世界之前”状态，但不解释后续变化。播放约 15 秒完整演出，让测试者自行转头。

- 是否注意到天花板退去，而不是只看到灯变蓝：____
- 是否看见墙与窗边界变化及墙后的完整外景：____
- 是否注意到草地、篝火和仍在原地的桌椅、画架：____
- 结构变化的次序是否清楚，视线是否跟得上：____
- 是否感觉熟悉房间被新世界吞没：____
- “星空出现的时候，你觉得是换关了吗？”（原话）____

比较初始房间和星空终态截图。理想回答是“这是同一个地方，但房间打开了、变成另一个世界”。
当前没有陌生玩家的有效答卷；技术自动十轮、截图评审和构建通过不能填入上述空白。
